# 2026-10-11 工作日志

## Excel对比工具 .bat 启动问题：最终根治方案

反复失败（PATH 选不到 Python / pythonw 真崩 / 中文乱码 / start 空标题 / echo 括号陷阱 /
%LOCALAPPDATA% 在 Explorer 双击上下文解析异常 → "系统找不到指定的路径" + "不是内部或外部命令"）。

**最终方案（已验证）**：彻底删除所有探测逻辑，直接用字面已知路径启动。
- 本机唯一可用 Python：`C:\Users\Administrator\AppData\Local\Programs\Python\Python313\`
  （pythonw.exe / python.exe 均带 tkinter + openpyxl 3.1.5）。
- `启动对比工具.bat`：`cd /d "%~dp0"` → `set "PY=<字面路径>\pythonw.exe"` →
  `if not exist "%PY%" goto :notfound` → `start "ExcelDiff" "%PY%" -X utf8 "%~dp0gui.py"`。
- `启动对比工具_调试.bat`：同上但用 python.exe（有控制台，崩溃可见）+ `pause`。
- 关键：不再依赖 `%LOCALAPPDATA%`、`PATH` 的 `for` 循环、括号 `echo`、空标题 `start`。

**验证**：文件纯 ASCII（调试版 0 非 ASCII）、无 BOM；`cmd /c` 解析测试 rc=0 且正确解析到
pythonw 路径与 gui.py；6 个 Python 模块（reader/compare/writer/dragdrop/app_icon/gui）
在系统 Python 下全部导入成功（gui 启动不会崩）。

**结论**：agent 沙箱 shell 与用户 Explorer 双击的 cmd 环境不同（变量/PATH 解析差异），
所以"agent 里测通过、用户双击失败"反复发生。根治 = 字面路径 + 零探测。
