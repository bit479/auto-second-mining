# 2026-10-23 工作日志

## 生成炮孔数据库：孔深三列统一四舍五入取整（v1.12）

### 用户要求
"自动生成炮孔数据库 excel 和 .mdb 的功能中，定位表的**最大孔深**、测斜表的**深度**、
pit_blast 的**至** 三列内容数值全部调整为四舍五入保留为整数。"

### 原来的口径（不一致）
* `.xls` 写 3 位小数（`_write_xls` 里 `num3` 格式 + 原值 `hole.depth`）；
* `.mdb` 已经取整（`float(math.floor(h.depth + 0.5))`）。
  两边不一致，用户看到的 xls 是 9.158、mdb 是 9。

### 改动（`core/make_database.py`）
* 新增 `round_int()`：`Decimal(str(v)).quantize(Decimal("1"), ROUND_HALF_UP)`。
  **不能用内置 `round()`** —— 它是银行家舍入（`round(8.5)=8`），跟 Excel/3DMine 对不上。
* `_write_xls`：三列改用 `round_int` + 整数格式 `"0"`（新增 `num0` 样式）；
  坐标 E/N/R 保持 `num3` 3 位小数。
* `_write_mdb`：三列统一走 `round_int`，删掉 `math.floor`（`math` 也随之不再用）。
* 新增边界检查：取整后为 0 的孔（如设计孔深 0.4 m）直接报错并点名工程号。
