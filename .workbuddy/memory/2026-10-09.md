需求：把若干份 3DMine 炮孔数据库报告（handle\工作簿1/2/3.xlsx …）汇总成一份
成果表（handle\3940平台 1008炮孔数据报告.xlsx）。

### 数据规律（从样本反推，已验证）
- 源文件：A1 大标题「3DMine 炮孔数据库报告」，第 2 行表头
  `类型 / 体号 / 体积 / 重量 / 平均品位(Au) / 金属量`，数据行后跟「小计」行。
- 成果表：A1:F1 合并标题；第 2 行表头（金属量列写作「金属量（百克）」）；
  按品位档降序归组（1.500-3.000 → 1.000-1.500 → 0.500-1.000），每组明细 + 小计，
  末尾合计；小计/合计写 Excel 公式。
- **平均品位 = 金属量 × 100 ÷ 重量**（不是算术平均），这是最关键的口径。
- 汇总区（第 1-10 行）全表细边框；下方隔 8 行追加各源文件原始报告，附录区无边框、
  标题加粗。字体「等线」，标题 10 号加粗，其余 11 号；E 列格式 `0.00_);[Red]\(0.00\)`。

### 实现

`src/blast_report`（schema/parser/builder，业务）。入口 `main.py`（CLI）+ `gui.py`（tkinter）
+ `启动汇总工具.bat`。`tests/test_merge.py` 与人工成果逐值比对，8 行全 OK。

### 环境坑
- **.bat 编码（踩过）**：cmd.exe 按 GBK 解析 .bat，文件若按 UTF-8 写中文，会被拆成
  乱码指令报「'xxx' 不是内部或外部命令」。解决办法：`.bat` 只写 ASCII（英文），
  中文提示交给 Python 打印（`bootstrap.py`）。bat 里加 `chcp 65001` +
  `set PYTHONIOENCODING=utf-8`。
- 托管 Python（3.13.12）无 tkinter；系统 Python 3.13.16 有 tkinter 且有 openpyxl 3.1.5，
  GUI 要用系统 Python 跑。
- 正则 `[<>≥≤]=?` 里 `?` 只作用于 `=`，导致字符类变成必选 —— 正确写法 `[<>≥≤]?=?`。
