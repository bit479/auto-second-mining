## 新建「Excel 对比工具」（D:\WK\N CRT\Excel对比工具）

需求：对比两个 Excel 的不同并输出报告。用户选择：逐单元格对比 + Excel 报告(差异高亮) + 新建独立程序
（不复用 Excel处理工具 框架，单独一套，但思路一致）。

### 结构
- `reader.py`：读 xlsx/xlsm（data_only 取公式值）/csv（utf-8-sig→utf-8→gbk 兜底）/xls（需 xlrd，缺失则友好报错）。
  统一结构 {sheet: [[cell,...]]}。
- `compare.py`：逐工作表、逐单元格比对。type: changed/only_a/only_b；数值按容差 1e-9，
  字符串/数字混合也按 float 归一比较；空白(None/空串/纯空格)视为相等。输出 sheets 列表 + totals 统计。
- `writer.py`：写 xlsx 报告，3 类 sheet——
  1) 汇总（文件路径/各表行列数/修改·仅A·仅B·差异合计/总计）
  2) 差异清单（工作表/坐标/类型/A值/B值，类型列颜色标注）
  3) 对比_<表名> 高亮可视化（修改=黄 FFF2CC / 仅A=绿 C6EFCE / 仅B=红 FFC7CE）
- `main.py`：CLI，`python main.py A B [-o out.xlsx]`，无参数启动 GUI。
- `gui.py`：tkinter 界面，选 A/B/输出、开始对比（线程执行防卡）、日志、打开报告。
- `启动对比工具.bat`：纯 ASCII，`for %%X in (pythonw python py python3)` 探测带 tkinter+openpyxl 的 python，
  用 `%~dp0gui.py` 启动（避免中文路径乱码）。

### 验证
- `tests/selftest.py`：造已知差异样例，断言 changed=2/only_a=6/only_b=3、sheet 结构、高亮颜色，全部通过。
- CLI 实跑验证：报告正确，差异清单逐条列出。

### 踩的坑（已修）
**高亮可视化网格最初只从文件A生成**，导致「仅B存在」的单元格（A里没有）根本不出现在网格里、
自然也不高亮。改为取 A、B 两文件**并集**维度，单元格显示 B 的值(无则 A 的值)，再按 mark 上色。
对比单元格时 only_a/only_b 分支不计 `compared`（只在两文件都有的格计入 compared），统计口径一致。

## 修复「启动对比工具.bat 启动不了」（10-10 后续）

### 根因
原 .bat 只靠 `where` 在 PATH 里找 python/pythonw/py/python3。但本机系统 Python
`C:\Users\Administrator\AppData\Local\Programs\Python\Python313`（带 tkinter+openpyxl）
**没加进 PATH**；PATH 里第一个 `pythonw`/`python` 反而是托管版
`C:\Users\Administrator\.workbuddy\binaries\python\versions\3.13.12`（**无 tkinter**），
`py` 启动器才指向系统版。用户桌面双击时若 PATH 未配 Python，for 循环全落空 → 走到
「not found」分支/静默。

### 修复
重写 `启动对比工具.bat`：
1. 先试 PATH（pythonw/python/py），import tkinter+openpyxl 成功才用；
2. PATH 里没有就**直接探测安装目录**：`%LOCALAPPDATA%\Programs\Python\Python3xx`、
   `C:\Program Files\Python3xx`、`C:\Python3xx` —— 不依赖 PATH；
3. 顶部 `cd /d "%~dp0"` 保证相对路径正确；
4. 优先 `pythonw`（无控制台），无则用 `py`/`python`。
`gui.py` 入口加顶层 try/except 兜底：pythonw 静默崩溃改为弹窗 + 写 `gui_error.log`。

### 验证（python subprocess 跑 .bat，注意 agent 无桌面 `start` 会返 255，属环境副作用）
- 干净 PATH（无 python）：检测选到 `PYW=C:\Users\Administrator\AppData\Local\Programs\Python\Python313\pythonw.exe` ✅
- 完整 PATH：检测选到 `PY=py`（启动器，带 tkinter）✅
- 直接 `pythonw gui.py` 限时 6s 存活、无 gui_error.log、GUI 正常起来 ✅
- 关键坑：`.bat` 绝不能选托管版 pythonw（无 tkinter）；检测顺序应跳过它（import 失败即跳过）。
