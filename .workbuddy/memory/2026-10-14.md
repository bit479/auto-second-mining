# 2026-10-14 工作日志

## 新建「单日数据并入总表」功能并集成进 Excel处理工具

### 需求
把某一天的 3 份单日数据并入对应 3 份 2026 年总表：
- `1、3940平台 炮孔数据库1008.xls` → `1、北部山头3940平台 炮孔数据库-2026.xls`
- `2、3940平台炮孔数据库1008.mdb` → `2、北部山头3940平台炮孔数据库-2026.mdb`
- `3940平台 1008炮孔数据报告.xlsx` → `3、北部山头3940平台炮孔数据报告-2026综合.xlsx`

### 摸清的数据结构（重要）
- **炮孔数据库 xls / mdb 同构**：三张表 `定位表`(工程号/开孔坐标E/N/R/轨迹类型/最大孔深)、
  `测斜表`(工程号/深度/方位角/倾角)、`pit_blast`(工程号/从/至/Au)。
  mdb 另有 3DMine 元数据表 `config_table_3dmine`/`style_table_3dmine`/`constraint_table_3dmine`（不能碰）。
  单日 xls 多一张含历史垃圾数据的 `Sheet1`，总表没有 → 并入时忽略。
- **mdb 特性**：`pit_blast` 在 Access 里有 `(工程号, 从)` 唯一索引 → 判重必须按两列；
  `定位表`/`测斜表` 无索引，`statistics()` 返回空。ODBC 驱动不支持 `SQLPrimaryKeys`。
- **xls 里 mdb/xls 数值精度不同**（3DMine 导出差异）：如 最大孔深 xls=11.101 / mdb=11.0。
  两套数据独立追加，不做交叉修正。
- **报告 xlsx 结构**：总表 = 从上到下堆叠的"日报告块"，每块 = 标题行 + 表头行 + 明细 + 小计 + 合计，
  块间空 1 行。0915/0922 的块已验证该规则。单日报告 r9 之后是"3DMine 炮孔数据库报告"附录 → 不进总表。
- **3960 平台总表用「总计」结尾，新报告用「合计」** → 两种都当块尾。

### 实现
新增 `Excel处理工具/src/daily_merge/`：`schema.py`（表结构/判重键/文件探测模式）、
`discover.py`（自动探测六文件、向上回溯总表目录、生成计划）、`db_xls.py`、`db_mdb.py`、
`report_xlsx.py`、`pipeline.py`（预演→备份→并入→复核→还原）。

关键技法：
- **xls 保真写入**：`xlutils.filter.XLWTWriter` + `process(XLRDReader(...))`，
  再用 `writer.style_list[xf_index]` 取原单元格样式给新增行，字体/列宽/其余表全保留。
  （`xlutils` 2.0.0 与 `xlrd` 2.0.2 兼容，round-trip 0 差异）
- **报告块粘贴**：`openpyxl.formula.translate.Translator(value, origin=...).translate_formula(target)`
  做公式行偏移平移；`copy.copy(cell.font/border/fill/alignment/protection)` + `number_format` 搬样式；
  合并区域按 delta 平移。
- **mdb 追加**：pyodbc + `Microsoft Access Driver (*.mdb, *.accdb)`，`autocommit=False` 事务提交。
- **坑**：自定义 `DailyTab._options()` 会覆盖 tkinter `Misc._options` 导致 `AttributeError` → 改名 `_merge_options`。

### 集成
`main.py` 增加 `--daily` / `--restore` 等参数组；`gui.py` 改成 `ttk.Notebook` 两个标签页
（保留模块级 `set_app_user_model_id` / `set_window_icon` / `launch(tab=)`，`tools/*.py` 仍可用）；
新增 `启动单日并入.bat`；`bootstrap.py` 区分 REQUIRED(openpyxl) 与 EXTRA(xlrd/xlwt/xlutils/pyodbc)。

### 验证
`tests/test_daily_merge.py` 30 项断言全通过：xls/mdb 追加行逐值一致（70→120）、
报告块落位 r23、公式 `=C3+C4`→`=C25+C26`、重复执行判重为 0 新增、备份还原生效。
真实文件只读预演结果与沙箱一致。**真实总表尚未写入**（等用户确认）。

### 顺带发现（待用户核对）
3960 平台单日报告 `3960平台 1008炮孔数据报告.xlsx` 本身合计公式有误：
`合计=C5+C8` 漏掉第 4 行小计并把体号 2 重复计入 → 体积少 225.042、重量少 607.613、金属量多 26.639。
