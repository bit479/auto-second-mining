# 项目长期记忆 —— 北部山头炮孔数据（N CRT）

## 数据目录约定

平台数据根目录：`北部山头<平台>2026\`（3940 / 3960 两套，结构一致）

```
北部山头3940平台2026\
├── 1、北部山头3940平台 炮孔数据库-2026.xls      # 总表 · 炮孔数据库(Excel)
├── 2、北部山头3940平台炮孔数据库-2026.mdb       # 总表 · 炮孔数据库(Access)
├── 3、北部山头3940平台炮孔数据报告-2026综合.xlsx # 总表 · 综合报告
├── 5、 北部山头3940平台二次圈矿矿块图-2026综合.dwg
├── 6、北部山头3940平台二次圈矿矿块图\
└── 7、单日数据\北部山头3940平台-<MMDD>\        # 每期单日数据
    ├── 1、3940平台 炮孔数据库<MMDD>.xls
    ├── 2、3940平台炮孔数据库<MMDD>.mdb
    ├── 3940平台 <MMDD>炮孔数据报告.xlsx
    └── 5、 北部山头3940平台二次圈矿矿块图<MMDD>.dwg
```

* 日期代号 = 目录名末尾 4 位数字（`-1008` → `1008`），也可从工程号 `BS-3940-1008-P12` 提取。
* 工程号格式：`BS-<平台>-<MMDD>-P<n>`，另有个别 `BL<n>`。
* 备份命名习惯：`<原名>_并入<日>.bak`（DWG 与数据总表统一用这个后缀）。

## 数据表结构

炮孔数据库（xls 与 mdb 同构）三张表：

| 表 | 列 |
|---|---|
| 定位表 | 工程号 · 开孔坐标E · 开孔坐标N · 开孔坐标R · 轨迹类型 · 最大孔深 |
| 测斜表 | 工程号 · 深度 · 方位角 · 倾角 |
| pit_blast | 工程号 · 从 · 至 · Au |

* mdb 里还有 `config_table_3dmine` / `style_table_3dmine` / `constraint_table_3dmine` 三张 3DMine 元数据表，**合并时不可改**。
* mdb 的 `pit_blast` 带 `(工程号, 从)` 唯一索引 → 判重必须按两列。
* xls 与 mdb 的数值精度不同（3DMine 导出差异，如最大孔深 11.101 vs 11.0），两套独立维护，不做交叉修正。

## 报告格式

单日报告 = 标题行 + 表头(类型/体号/体积/重量/平均品位(Au)/金属量（百克）) + 各品位档明细 + 小计 + 合计，
其后可跟若干"3DMine 炮孔数据库报告"附录。综合总表 = 这些"标题→合计"块从上到下堆叠，块间空 1 行。

* 平均品位 = 金属量 × 100 ÷ 重量（不是算术平均）。
* 老报告用「总计」结尾，新报告用「合计」。

## 工具

`D:\WK\N CRT\Excel处理工具\`（openpyxl + xlrd/xlwt/xlutils + pyodbc）

* 标签页①「炮孔数据报告汇总」：多份 3DMine 报告 → 一份炮孔数据报告

**改 `.bat` 时内容必须保持纯 ASCII**：cmd.exe 按 GBK 解析，写中文 UTF-8 会变成乱码指令。
