## 一、本版新增：全局 TXT 坐标拖放导入

把坐标 TXT **拖到软件任意页面**即可，不用先打开「炮孔数据库生成」：

1. 自动识别文件编码（UTF-8 / UTF-8 BOM / GBK / GB18030）与分隔符（逗号 / 制表符 / 空格 / 分号）；
2. 自动识别平台、日期、台阶（先看文件内标注与炮孔编号，再看文件名，都没有就留空等人工填）；
3. 解析炮孔编号与 E / N / R 坐标，统计总数 / 有效 / 异常 / 重复；
4. 自动跳到「炮孔数据库生成」页，把参数与炮孔数据填好、预览列出；
5. 有坏坐标、重复孔号等问题时**禁用「生成」按钮**并列出问题，不会把脏数据写进数据库。

补充说明：

- 不兼容的格式（GBK、制表符、带表头…）会自动生成一份 5 列 UTF-8 规范化副本供生成使用，**原文件一个字节都不改**；
- 原有手工选择 TXT、解析预览、生成的流程完全保留；
- 圈矿算法、品位分级、参数口径、数据库结构均未改动。

## 三、使用方法

1. 把 zip 解压到一个**可写目录**（如 `D:\工具\二次圈矿\`，不要放 `C:\Program Files\` 根下）；
2. 双击 `二次圈矿智能工作台.exe`；首次运行会在 exe 同目录生成 `data\`（参数、品位分级、模板、最近记录）；
3. 把坐标 TXT 拖进窗口任意位置，或进「炮孔数据库生成」页手工选择；
4. 日常流程不变：选数据库/综合图 → 单炮区二次圈矿 → 一键出三件套。

**环境要求**：Windows 10 1809+ / 11，64 位；无需安装 Python 或任何运行库；全程离线。
AutoCAD 仅在选择"圈完转 DWG 2010"时才需要，不勾选则只出 DXF。

**首次启动**：单文件需要解包，冷启动约 10–15 秒属正常；之后系统缓存会让它快一些。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| SmartScreen 提示"未知发布者" | 点「更多信息 → 仍要运行」。exe 未做代码签名，不影响功能 |
| 杀毒软件拦截 | 把 exe 所在目录加入信任（PyInstaller 单文件偶发误报） |
| 首次运行报错说无法写 data | exe 放在了只读目录，换到可写目录再运行 |
| 拖入 TXT 提示"只支持 .txt" | 目前只接收本地 `.txt` / `.dat`；xls、dwg 等请走页面上的「浏览」 |
| 平台/日期没识别出来 | 文件里没有标注、孔号也不含平台日期、文件名也不含；页面手工填即可 |
| 拖入后提示"有问题，生成被禁用" | 看卡片里的红条，按提示修正 TXT（重复孔号、坏坐标、空工程号） |
