# 二次圈矿智能工作台 · UI 设计规范 v1.16

> 适用范围：`client/ui_v2/` 全部界面。任何新增页面 / 组件都应遵守本文件；
> 令牌集中在 `client/ui_v2/theme.py`，组件集中在 `components/`，页面不得再手写颜色与像素。

---

## 1. 设计定位

专业工业软件 + 现代极简桌面应用：深色「机箱」包住浅色「工作面」，
靠留白、1px 分隔线、字号层级建立秩序；不使用渐变、发光、重投影、装饰性插图。

三条硬规则：

1. **颜色只有一个来源**：`theme.py`。品位分级颜色例外，只允许来自 `grade_profiles.json`
   （经 `services/config.py` 读取），保证界面图例与 CAD 出图同色。
2. **图标只有一个来源**：`icons.py`（内联 SVG，24×24 网格）。禁止 Unicode 字符、emoji、外部 PNG 充当功能图标。
3. **尺寸只有一套刻度**：4px 栅格（4 / 8 / 12 / 14 / 16 / 20 / 24）。

## 3. 布局与栅格

```
┌──────────────────────────────────────────────────────────────┐
│ 标题栏 56px：品牌(236) │ 面包屑 │ 项目/平台/矿段/状态 │ 窗口按钮 │
├────────────┬─────────────────────────────────────────────────┤
│ 侧边栏     │ 页头：H1 + 说明 + 页级动作（固定，不滚动）        │
│ 236px      ├─────────────────────────────────────────────────┤
│ 分组导航   │ 内容区（QScrollArea，24px 内边距，14px 间距）     │
│ 20px 图标  │                                                 │
│ 38px 行高  │                                                 │
│            │                                                 │
│ 版本/构建  ├─────────────────────────────────────────────────┤
│            │ 底部状态条 28px：状态 · 数据目录                 │
└────────────┴─────────────────────────────────────────────────┘
```

- 主内容列比例：主区 : 辅区 = 3 : 2（`Page.two_columns()`），间距 14px。
- 卡片内边距统一 18 / 15 / 18 / 16，卡片内元素间距 10–12px。
- 页面内容一律放进 `QScrollArea`，横向滚动条始终关闭；表格自身也不出现横向滚动条。

## 4. 组件规范

### 4.1 卡片（`Card` / `TableCard` / `StatTile` / `QuickCard`）

| 组件 | 结构 | 尺寸 |
|---|---|---|
| `Card` | 标题 14/600 + 说明 12/muted + 内容 | 圆角 10，1px `BORDER` |
| `TableCard` | 标题行 + 表格 / 空状态 | 行高 34，表头 34 |
| `StatTile` | 标签 12 + 数值 24/600 + 说明 11 | 内边距 16/14，最小宽 150 |
| `QuickCard` | 36×36 图标底板 + 标题 13/600 + 说明 12 | 最小高 88，hover 淡蓝底 |

`QuickCard` 的图标底板按语义着色：主入口用主色淡底，辅助入口用中性灰底，
不得整排使用高饱和蓝。

### 4.2 按钮

| 类型 | 外观 | 用途 |
|---|---|---|
| Primary | 钢蓝实底 + 白字 600 | 每屏最多 1 个主操作 |
| Secondary | 白底 + 1px 边框 | 常规操作 |
| Accent | 铜褐实底 | 写参数等「有副作用」的操作 |
| Ghost | 透明 + 主色文字 | 卡片内轻量入口、链接 |
| Danger | 淡红底 + 红字 | 替换原件等危险操作 |

统一高度 34px；hover 提亮/加深一档；pressed 再深一档；disabled 降对比并去掉边框强调；
focus 使用 `FOCUS` 描边。同一行内的按钮高度必须一致。

### 4.3 输入控件

- 高度 34px，圆角 6px，边框 `BORDER_STRONG`，focus 变 `FOCUS`。
- 校验状态：`state="ok"` 淡绿、`warn"` 淡黄、`error"` 淡红，由 `FileRow.set_state()` 驱动。
- 下拉框由 `W.combo()` 创建（自绘 chevron），不使用原生箭头，保证 DPI 下清晰。
- 勾选框由 `W.CheckRow` 自绘（15px 圆角方框 + 白色对勾），避免 QSS 覆盖导致「只有色块没有勾」。

### 4.4 表格

- 无网格线，行间 1px `BORDER_SOFT`；表头 `BG_SOFT` + 12px/600 muted。
- 选中行 `PRIMARY_LIGHT`，hover 行 `#F5F9FC`。
- 文本一律 `ElideRight`，完整内容进 tooltip；**禁止横向滚动条**。
- 空数据时必须展示空状态，不允许只留表头。

### 4.5 徽章与状态

`Badge` 为胶囊：高 20px，11px/600，前景/底色由 `theme.status_color()` 决定。
标题栏的状态胶囊带 8px 圆点：空闲绿、运行中橙。

### 4.6 空状态（`EmptyState`）

图标 34px（`TEXT_FAINT`）+ 标题 13/600 + 说明 12 + 可选 Ghost 动作。
用于：无任务、无成果、未扫描、无预览数据等场景。

## 5. 图标规范

- 24×24 viewBox，`stroke-width: 1.75`，`stroke-linecap/linejoin: round`，`fill: none`。
- 尺寸：导航 20px、按钮 16px、功能卡 22px、窗口控件自绘 10px 线条。
- 图标必须放在**固定尺寸**的 QLabel 或 QPushButton.iconSize 中，不得由布局压缩。
- 颜色随主题：浅底 `TEXT_MUTED`/`TEXT_SUB`，深底 `#A6BCCF`（hover `#DCE8F3`，选中 `#DFF0FB`）。
- 新增图标写进 `icons._SVG`，命名用短横线小写（如 `file-text`）。
- 禁止：特殊 Unicode 符号（如 `❮`、`⛏`）、emoji、外部图片、运行时网络加载。

---

## 6. 沉浸式标题栏

- 高度 56px，底色 `CHROME`，与侧边栏连成一体；下方 1px `CHROME_LINE`。
- 左：30×30 圆角 Logo（`#17364F` 底 + 浅蓝镐头）+ 产品名 14/600 + 英文副标 9px/字距 1.6。
- 中：面包屑「分组 › 页面」，分组 12px `CHROME_MUTED`，页面 13px `#D6E3EF`。
- 右：信息胶囊（项目 / 平台 / 矿段）+ 状态胶囊 + 设置入口 + 最小化/最大化/关闭。
- 窗口按钮 46×56，hover 白 8% 叠加，关闭 hover `#C42B1C`。
- 原生能力不妥协：`WM_NCHITTEST` 交回系统处理拖动、双击最大化、边缘缩放与 Win11 Snap Layout；
  `WM_GETMINMAXINFO` 限制最大化到工作区，不遮挡任务栏。

## 7. 侧边导航

- 宽度 236px，底色 `CHROME`，右侧 1px 分隔。
- 分组：工作空间 / 数据管理 / 系统管理，标题 11px/600 `CHROME_FAINT`，字距 0.6。
- 菜单项：高 38px，左内边距 14px，图标 20px，间距 11px，文字 13px。
- 选中：`CHROME_ACTIVE` 底 + 左侧 3×16 亮蓝标识条（始终占位，切换时不产生位移）+ 白色 600 文字。
- hover：`CHROME_RAISED`，文字/图标提亮，不做高饱和高亮。
- 底部：版本号 12px + 构建信息 11px（运行方式 + 日期）。

---

## 8. 交互状态

| 状态 | 表现 |
|---|---|
| hover | 背景提亮一档 / 边框加深一档，过渡即时（无动画） |
| pressed | 再深一档 |
| focus | 1px `FOCUS` 描边（键盘可达） |
| disabled | 文字 `#A7B2BE`，底色 `BG_SOFT`，边框 `BORDER` |
| 运行中 | 状态胶囊转橙，标题栏状态文字显示任务名，底部状态条显示「正在执行：…」 |

---

## 9. 文案规范

- 页面标题 4–8 字，说明一句话 20–34 字，句末不加句号。
- 按钮用动词短语：「开始汇总」「生成合并副本」「确认替换综合图原件…」（危险操作带省略号）。
- 数值必须带单位：`g/t`、`m²`、`m³`、`t`、`百克`。
- 不伪造数据：没有数据就显示 `—` 或空状态，不填演示数字。

---

## 10. 验收口径

1. 1920×1080 / 1600×900 / 1366×768 × 100% / 125% / 150% 下无图标裁切、无按钮文字截断。
2. 页面内容区横向滚动条最大值必须为 0。
3. 所有页面标题左基线一致（24px 起始）。
4. 表格空数据必须有空状态。
5. 品位图例颜色与 `grade_profiles.json` 完全一致。
6. 业务算法、参数、口径、公式零改动。
