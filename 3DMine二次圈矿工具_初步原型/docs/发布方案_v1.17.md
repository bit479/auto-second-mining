# 二次圈矿智能工作台 v1.17 · 发布方案（单文件 exe）

> 目标：把整套工具（界面 + 圈矿算法 + Excel 工具 + 验收脚本）打成**一个 exe**，
> 拷过去双击就能用：不装 Python、不装 PySide6、不装 VC 运行库、不联网。

---

## 1. 产物形态

| 项 | 决定 |
|---|---|
| 形态 | **单文件 exe**（PyInstaller `--onefile --windowed`） |
| 文件名 | `二次圈矿智能工作台.exe` |
| 体积 | 130,307,503 字节（≈124.3 MB，实测） |
| 启动 | 双击即开；单文件需解包，冷启动实测 **17–19 秒**，热启动更快 |
| 安装 | **免安装**。解压即用，删除即卸载（不写注册表、不装服务） |
| 附带 | 同目录首次运行自动生成 `data\`（可写配置与输出根） |
| 并行产物 | 目录版 `dist\二次圈矿智能工作台\`（≈284 MB，冷启动 ≈5 秒），仅内部/排错用，不随本次 Release 分发 |

**为什么坚持单文件**：现场机器多是"拷个文件过去就能跑"，单文件最省事；
代价是每次启动要解包到 `%TEMP%`。如果更在意启动速度，改用目录版即可，功能完全一致。

---

## 2. 目标平台与架构

| 项 | 值 |
|---|---|
| 系统 | Windows 10 1809+ / Windows 11（x64） |
| 架构 | **x64 专用**（打包机 `AMD64`，Python 3.13.16 x64、PySide6 6.12.0） |
| 不支持 | 32 位 Windows、Windows ARM64、Linux/macOS（PyInstaller 不能跨平台交叉编译） |
| 构建机 | Windows 11（10.0.26200），因此 exe 内嵌的是该版本的 Python 与 Qt 运行库 |
| 显示 | 支持 100% / 125% / 150% 缩放；最小窗口 1180×700 |

## 3. 版本号与构建配置

| 项 | 值 | 来源 |
|---|---|---|
| 产品版本 | `v1.17` | `client/ui_v2/services/paths.py` 的 `APP_VERSION`（唯一来源） |
| 构建日期 | `2026-11-06` | 同文件 `BUILD_STAMP` |
| 界面显示 | 侧栏底部 `v1.17` + `单文件 exe · 2026-11-06` | 运行时读上面的常量 |
| 文件属性 | `FileVersion / ProductVersion = 1.17.0.0`，ProductName=二次圈矿智能工作台，CompanyName=bit479 | 打包时由 `build_exe.py` 生成 `version_info.txt` 传入 `--version-file` |
| 图标 | `assets/app.ico`（多尺寸 ico） | `--icon` 内嵌到 exe |
| 入口 | `client/ui_v2/app.py` | `--windowed`（无控制台窗口） |

关键打包参数（`_probe/build_exe.py`）：

```
--onefile --windowed --noconfirm --name 二次圈矿智能工作台
--icon assets/app.ico  --version-file <生成的 version_info.txt>
--paths client
--add-data core;core            --add-data excel_tools;excel_tools
--add-data _probe;_probe        --add-data sample_data;sample_data
--add-data assets;assets        --add-data 圈矿参数.json;.
--hidden-import <ui_v2 各模块、numpy/scipy/shapely/ezdxf/matplotlib/openpyxl/pyodbc…>
--exclude-module <QtWebEngine/QtQuick/QtQml/Qt3D/QtCharts/QtMultimedia…>
```

- 关键数据**构建期就做了一份干净的暂存树**（去掉 `__pycache__`、`_out`、`归档`、`bak`），
  避免把中间产物打进 exe；
- 旧产物不删，改名挪到 `build/_replaced/`，随时可回退；
- 每次构建用独立 `workpath`，不受上一轮缓存/占用影响。

## 4. 内置资源与运行时数据

**随 exe 打包（只读，解包在 `%TEMP%\_MEIxxxx`）**

| 内容 | 说明 |
|---|---|
| 界面图标 | 全部是内联 SVG（`icons.py`），**零外部图片** |
| `core/`、`excel_tools/`、`_probe/` | 圈矿算法、报告工具、验收脚本 |
| `assets/3dmine_template.mdb` | 炮孔数据库 .mdb 模板 |
| `圈矿参数.json`、`excel_tools/config/grade_profiles.json` | 出厂默认参数与品位分级 |
| `sample_data/`、`README.md`、`项目结构说明.md` | 示例与说明 |

**首次运行自动铺到 exe 同目录 `data\`（可写，之后所有读写都在这里）**

```
二次圈矿智能工作台.exe
data\
├── 圈矿参数.json                     ← 参数三层覆盖写这里
├── excel_tools\config\grade_profiles.json
├── assets\3dmine_template.mdb
└── .ui_state.json                    ← 最近任务/成果、窗口位置
```

> 因此：**exe 要放在可写目录**（例如 `D:\工具\二次圈矿\`、U 盘），
> 不要放 `C:\Program Files\` 根下（无写权限时首次运行无法建 `data\`）。
> 输出目录默认在"坐标 TXT 同目录"，与 exe 位置无关。

## 5. 运行时依赖

| 项 | 是否需要 | 说明 |
|---|---|---|
| Python / PySide6 | **不需要** | 已打进 exe |
| Visual C++ 运行库 | **不需要** | PyInstaller 会把所需 DLL 一并带上 |
| .NET / Java / 浏览器内核 | 不需要 | 界面是 Qt Widgets，不用 WebView |
| 网络 | 不需要 | 全程离线，图标不走网络 |
| AutoCAD | **可选** | 只有勾选"圈完转 DWG 2010"时才调用；不勾则只出 DXF，不影响其它功能 |
| 权限 | 普通用户 | 不需要管理员（除非放在受保护目录） |

**签名状态**：exe **未做代码签名**。首次下载/拷贝运行时 Windows SmartScreen 可能提示
"未知发布者"，点「更多信息 → 仍要运行」即可；如需消除提示，需购买代码签名证书后重签（不影响功能）。

## 6. 打包流程（可复现）

```bat

:: 1) 确认版本号

:: 3) 打包单文件
打包exe.bat                                        :: = build_exe.py（onefile）

:: 4) 生成发布包（exe + 说明 + 校验，zip 到 auto-second-mining\release_v1\）
python _probe\make_release_exe.py v1.17
```

打包脚本会自动：生成版本资源 → 干净暂存树 → PyInstaller → 挪走旧产物 → 报告体积。

## 8. 发布说明要点

**版本变更（相对 v1.15）**

- v1.16：界面全面重构 —— 沉浸式深蓝标题栏（原生拖动/双击最大化/Win11 贴靠）、
  全站图标系统重写（修掉图标残缺）、侧栏与工作台重做、统一设计令牌；
- v1.17：**全局 TXT 坐标拖放导入** —— 任意页面拖入 TXT → 自动识别平台/日期 →
  解析炮孔（UTF-8/GBK、逗号/制表符/空格、带表头均可）→ 自动跳到「炮孔数据库生成」
  并填好参数与数据；不兼容格式自动生成规范化副本，原文件不动；
- 圈矿算法、品位分级、参数口径、数据库结构**均未改动**。

**使用方式（写进 `使用说明.txt`）**

1. 把 zip 解压到可写目录（别放 Program Files 根下）；
2. 双击 `二次圈矿智能工作台.exe`，首次运行会在旁边生成 `data\`；
3. 把坐标 TXT 拖进窗口任意位置，或走「炮孔数据库生成」页手工选择；
4. 关掉杀毒误报：把 exe 所在目录加入信任（PyInstaller 单文件偶发误报）。

**校验（本次实际值）**

```
zip     123.5 MB
sha256  9bbfa0f132582f171e217ef1a5b8c381dd23f24acffa7b02746dcdcfac4c543c
exe     sha256 ce027dba5b2eb175532aba34…（完整值见包内 SHA256SUMS.txt）

certutil -hashfile second-mining-workbench-v1.17-win64.zip SHA256
```

与 `SHA256SUMS.txt` 对照即可。

**已知限制**

- 单文件冷启动 10–15 秒（解包所致）；
- 未签名，SmartScreen 会提示；
- 品位表仍需人工粘贴（TXT 里没有品位）；
- 仅 x64 Windows，不支持 32 位 / ARM。
