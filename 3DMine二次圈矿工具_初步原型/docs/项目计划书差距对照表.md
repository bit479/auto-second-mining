# 项目计划书差距对照表

> 状态定义：**已完成**（代码+测试证据）/ **部分完成**（有实现但明显缺口）/ **未开始**（无实现）/ **待验证**（有代码缺有效验证）/ **需要调整**（原计划不适应当前）。
> 所有「代码证据」均为本次实际读码所得（含行号），非仅凭文件名/README 判断。
