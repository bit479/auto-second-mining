## 本版新增：全局 TXT 坐标拖放导入

1. 自动识别编码（UTF-8 / UTF-8 BOM / GBK / GB18030）与分隔符（逗号 / 制表符 / 空格 / 分号），带不带表头都能读；
2. 自动识别平台、日期、台阶 —— 先看文件内标注与炮孔编号（`BS-3940-0915-P1`），再看文件名，都没有就留空等人工填；**不从高程反推平台、不塞当天日期**，每项都标来源；
3. 解析炮孔编号与 E / N / R，统计总数 / 有效 / 异常 / 重复，逐条列出坏坐标、重复孔号、空工程号；
4. 自动跳到「炮孔数据库生成」，参数与炮孔数据直接填好并预览；
5. 有异常时**禁用「生成」按钮**，不让脏数据进库；与页面已有参数冲突时保留人工值并提供「采用识别值」。

不兼容的格式会自动生成一份 5 列 UTF-8 规范化副本供生成使用，**原文件一个字节都不改**。原有手工选 TXT → 预览 → 生成的流程完全保留。

## 使用

1. 解压到**可写目录**（如 `D:\工具\二次圈矿\`，不要放 `C:\Program Files\` 根下）；
2. 双击 `二次圈矿智能工作台.exe`；首次运行会在同目录生成 `data\`（参数、品位分级、模板、最近记录）；
3. 拖 TXT 进窗口任意位置，或进「炮孔数据库生成」页手工选择；
4. 日常流程不变：选数据库/综合图 → 单炮区二次圈矿 → 一键出三件套。

**环境**：Windows 10 1809+ / 11，64 位。AutoCAD 仅在选择「圈完转 DWG 2010」时才需要。
**首次启动**：单文件要解包，冷启动 15–20 秒属正常，之后走系统缓存会快得多（急用可自己用源码包跑）。
