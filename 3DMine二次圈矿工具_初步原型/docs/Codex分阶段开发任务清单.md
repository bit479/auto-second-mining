# Codex 分阶段开发任务清单

> 每个任务必须能**独立执行、测试、验收**。禁止一次性重构整个项目。
> 统一纪律：只读生产算法、新代码放独立模块、双轨对比、不覆盖生产参数/历史基准、可回滚。

---

## 第一批：基础任务（数据 + 质量 + 基线，必须最先做）

### 任务 T01 — 建立炮孔数据标准化模块
- **目的**：定义统一数据对象，隔离 Excel 解析细节。
- **当前问题**：`oreblocks.Hole` 只有 6 个字段，无多段样/地质对象；解析列位硬编码（`oreblocks.py:187-236`）。
- **文件**：新增 `core/data/models.py`、`core/data/readers.py`；`oreblocks.py` 仅加兼容调用。
- **实现要求**：`Hole`、`SampleInterval`、`Bench`/`Blast`、`GeologyFeature`；`readers.py` 做表头识别+字段映射，保留 `load_holes_xls` 原函数签名不变。
- **测试**：3 种表头/列序变体的 xls 能正确读入。
- **验收**：新模块可独立 import，读原 1008 数据库与 `load_holes_xls` 结果一致。
- **前置**：无。
- **风险/回滚**：纯新增，不接入生产，零回滚成本。

### 任务 T02 — 建立数据质量检查模块
- **目的**：异常数据不被静默吞掉。
- **当前问题**：重复工程号静默覆盖、缺失品位按废孔处理、多段化验未处理（D1）。
- **文件**：新增 `core/quality/check.py`、`core/quality/report.py`。
- **实现要求**：字段完整性、重复/近重复坐标、工程号重复、缺失品位 vs 真实低品位区分、多段化验（按确认规则）、异常孔深/品位、空间离群；输出结构化异常列表（文件/工作表/行/工程号 + 阻断/警告分级）。
- **测试**：构造重复/缺失/多段/负品位样本，断言每条异常可定位、级别正确。
- **验收**：关键异常可阻断或显式警告；原始文件不被修改。
- **前置**：T01；「多段样汇总规则」由地质负责人确认。
- **风险/回滚**：只读校验，不写回数据。

### 任务 T03 — 建立基线快照与参数地图
- **目的**：冻结 legacy_v1，形成参数特例清单。
- **当前问题**：无 legacy 标记、无参数特例统计（D8）。
- **文件**：新增 `_probe/audit_params.py`；README/版本说明补基线表。
- **实现要求**：统计所有 `platforms`/`blasts` 覆盖项（extrude/ring_mode/chain_left/right/exclude/cluster_exact/same/solo/exclude/seam_join/repair_tip），输出「参数地图」；生成 `legacy_v1` 标记（tag 或 `core/legacy/__init__.py` 兼容入口）。
- **测试**：跑一遍输出参数地图，与 `圈矿参数.json` 逐条一致。
- **验收**：参数地图 CSV/MD 可交付；历史 17 炮区特判一目了然。
- **前置**：无。
- **风险/回滚**：只读+新增文档。

### 任务 T04 — 成果可追溯（run_id + 参数快照 + 输入指纹）
- **目的**：每个成果可复现。
- **当前问题**：`deliver.py`/`run_strip.py` 的 `meta` 只有 platform/date/density，无 run_id/commit/参数哈希/输入指纹（D7，计划 §9.1）。
- **文件**：`core/run_strip.py`、`core/deliver.py`（仅增加，不改算量口径）。
- **实现要求**：每次运行生成 `run_id`（时间戳+短哈希），在输出目录写 `run_meta.json`（commit、参数快照、矿段档位版本、输入文件大小+mtime+md5、候选模型与选模原因、警告、成果清单）。
- **测试**：跑一次 1008，断言 `run_meta.json` 字段齐全且 md5 与输入文件一致。
- **验收**：同一输入可复现同一 run 元数据；报告里能查到参数来源。
- **前置**：T03。
- **风险/回滚**：只新增元数据文件，不覆盖成果。

## 第二批：核心圈矿算法优化（独立实验 + 双轨）

### 任务 T05 — 局部尺度与聚类实验模块
- **目的**：摆脱固定 15m 半径。
- **当前问题**：`pipeline.pick_zone` 固定 `adjacent_max`（D4）。
- **文件**：新增 `core/spatial/local_scale.py`、`core/spatial/cluster.py`。
- **实现要求**：k 近邻距离、局部密度、局部邻接图；DBSCAN 基线 + HDBSCAN 可选；参数由局部孔距辅助确定。
- **测试**：条带/弯曲/多分支/孤立簇/稀疏孔五类合成样本。
- **验收**：能输出多候选簇 + 各自规模/方向/紧凑度/孤立度，**不替换生产判断**。
- **前置**：T01。
- **风险/回滚**：独立目录，不接入 pipeline。

### 任务 T06 — 候选边界生成接口 + 多候选比较
- **目的**：一个炮区横向比较多个矿界候选。
- **当前问题**：`zone_outline` 内嵌 chain/alpha 分支，无统一候选接口（D4）。
- **文件**：新增 `core/boundaries/base.py`、`core/boundaries/candidates.py`。
- **实现要求**：统一接口 `build(xy, cfg) -> Candidate`；实现 PCA 外推、Alpha Shape、Concave Hull、Voronoi、各向异性外推；每个候选输出指标（面积/周长/紧凑度/矿孔覆盖/环外孔/碎片/修补面积/外推尺度）。
- **测试**：五类形态样本各生成≥2 候选并输出指标表。
- **验收**：候选几何可复现、可检查；指标齐全。
- **前置**：T05。
- **风险/回滚**：独立目录。

### 任务 T07 — 双轨对比流程（legacy_v1 vs candidate_v2）
- **目的**：不替换生产前提下量化新旧差异。
- **文件**：新增 `core/pipeline_v2/run.py`、`core/evaluation/metrics.py`、`core/evaluation/compare.py`。
- **实现要求**：同炮区读同一份已校验数据，分别跑 legacy 与 v2，输出对比报告（矿界 IoU、面积/体积/品位/金属量偏差、块数、孔归属、人工修正量、警告）。
- **测试**：1008 跑通，报告字段齐全。
- **验收**：双轨可运行，报告可审阅；**不把新参数写入生产配置**。
- **前置**：T06。
- **风险/回滚**：独立实验输出目录，零生产影响。

### 任务 T08 — 矿块邻接图与合并规则评分
- **目的**：让合并规则可解释。
- **当前问题**：碎片并入只按面积+平均品位差（`strip.py:1282-1308`），无公共边/贫化维度（D6）。
- **文件**：新增 `core/blocks/graph.py`、`core/blocks/merge_rules.py`。
- **实现要求**：Voronoi 单元为节点、公共边为边；记录公共边长/品位差/地质标签；合并评分含品位、空间、贫化（废孔占比）、稳定性维度；输出合并日志。
- **测试**：对比 0915/1004 的合并结果与人工图，说明差异原因。
- **验收**：合并过程可追溯、可解释。
- **前置**：T06。
- **风险/回滚**：独立模块，不覆盖 `average_blocks`。

## 第三批：计算准确性与地质约束

### 任务 T09 — 计算口径唯一化 + 3DMine 对账
- **目的**：统一公式并与 3DMine 逐块对账（D2）。
- **文件**：新增 `core/calculations/spec.py`、`core/calculations/reconcile.py`。
- **实现要求**：把「V_i=A_i×H_i、V=ΣV_i、T=Σ(V_i×ρ_i)、孔长加权品位、金属量=T×G/100」写成唯一口径；登记 `Block.compute` / `average_blocks` 含废孔分支 / `auto_blocks` 三处口径差异；读 3DMine `.3dm/.3ds` 单元导出逐块对账面积/体积/重量/品位/金属量；核对 `grade_lenght=int(round(depth))` 与 3DMine 四舍五入一致性。
- **测试**：至少 1 个含废孔 + 1 个不同品位 + 1 个边界单元的炮区逐块对账。
- **验收**：对账表逐块一致；口径差异有书面登记与负责人签字。
- **前置**：T04；需要 3DMine 单元导出样本。
- **风险/回滚**：只读对账，不修改任何公式。

### 任务 T10 — 综合图扫描可靠性改造
- **目的**：错误历史轮廓不进入算法（D3）。
- **文件**：`core/composite.py`（增强，不改合并逻辑）。
- **实现要求**：开口线不自动闭合（标记待人工）；3D Polyline 顶点 Z 校验；图层白名单（替代黑名单）+ 人工预览；缓存改源文件指纹（md5）而非 mtime。
- **测试**：2D/3D Polyline、闭合/未闭合、图层、缓存有效性样本。
- **验收**：COM 与 accoreconsole 结果一致；开口/异常实体不进入矿块集。
- **前置**：无（可独立）。
- **风险/回滚**：仅改扫描校验，合并口径不动。

### 任务 T11 — 地质约束接口（硬/软约束）
- **文件**：新增 `core/geology/feature.py`、`core/geology/constraints.py`。
- **实现要求**：地质界线（有坐标闭合/开口/属性线）、岩性编码、断层、蚀变的数据对象；硬/软约束语义与配置；先做「约束加载 + 可视化叠加」，不改变边界算法。
- **测试**：用一条人工界线验证叠加与语义解析。
- **验收**：约束可追溯、可配置、可预览。
- **前置**：T01；地质数据规范需地质人员提供。
- **风险/回滚**：独立模块，试接入。

## 附：可直接交给 Codex 的分阶段提示词

**P1（数据质量）**
> 任务：在 auto-second-mining 的 `3DMine二次圈矿工具_初步原型` 下新增 `core/data/` 与 `core/quality/`。不修改 `core/oreblocks.py` 的现有 `load_holes_xls` 行为。先读 `oreblocks.py`、`make_database.py`、`口径确认记录.md` 理解字段。实现：①`data/models.py` 定义 Hole/SampleInterval/Bench·Blast/GeologyFeature；②`quality/check.py` 对读取结果做重复工程号、缺失品位、多段化验、重复/近重复坐标、异常孔深、空间离群检查，输出结构化异常（文件/工作表/行/工程号 + 阻断/警告分级）；③`quality/report.py` 生成导入质量报告。用合成异常样本写单元测试。交付：代码 + 测试 + 质量报告样例。硬性要求：不修改生产算法、不写回任何数据。

**P2（空间识别实验）**
> 任务：新增 `core/spatial/` 与 `core/boundaries/`。先读 `pipeline.py:pick_zone`、`strip.py:zone_outline/_alpha_shape/_voronoi_cells`。实现局部 k 近邻尺度、DBSCAN/HDBSCAN 聚类实验，以及统一候选边界接口（PCA 外推、Alpha Shape、Concave Hull、Voronoi、各向异性外推）。每个候选输出面积/周长/紧凑度/矿孔覆盖/环外孔/碎片/修补面积。用五类合成形态（条带/弯曲/多分支/孤立簇/稀疏孔）写测试。不替换生产算法、不写回参数。交付实验代码 + 测试 + 候选对比报告。

**P3（双轨对比）**
> 任务：新增 `core/pipeline_v2/run.py` 与 `core/evaluation/`。同炮区读同一份数据，分别跑 legacy（`pipeline.run_blast`）与 candidate_v2，输出对比报告（IoU/面积/体积/品位/金属量偏差、块数、孔归属、人工修正量、警告）。候选选择不得使用独立测试人工图 IoU 作为在线选模。结果写入独立 experiment/run_id 目录，附 commit+参数快照。交付对比报告样例。

**P4（计算对账）**
> 任务：新增 `core/calculations/`。先读 `oreblocks.py:Block.compute`、`strip.py:average_blocks`、`口径确认记录.md` A 节。登记三种算量分支的口径差异；实现 `reconcile.py` 读 3DMine `.3dm/.3ds` 单元导出逐块对账面积/体积/重量/品位/金属量；核对 `grade_lenght=int(round(depth))` 与 3DMine 四舍五入一致性。不修改任何计算公式。交付口径登记 + 对账脚本 + 对账表样例。

**P5（综合图可靠性）**
> 任务：增强 `core/composite.py` 扫描校验。开口多段线不自动闭合（标记待人工）；3D Polyline 顶点 Z 校验；图层白名单 + 人工预览；缓存改源文件 md5 指纹。用 2D/3D Polyline、闭合/未闭合、图层样本写测试。不改变 `merge_outline` 合并口径。交付增强代码 + 测试。
