# 二次圈矿工具 · 项目结构说明（交接用）

> 这个工具做的事：**丢给它两个文件（炮孔数据库 Excel + 该平台综合图 DWG），一键出三件套**
> ——炮孔数据报告、二次圈矿矿块图（DWG 2010）、矿块边界线 .3ds。
> 算法口径全部写在 **`口径确认记录.md`**，那份是"以用户为准"的唯一依据；
> 当前验收状态与四道自检见 **`README.md`**；最近一次验收结果见 **`验收报告.md`**。

## 一、怎么跑

### 1. 图形界面

双击 **`启动二次圈矿工具.bat`**。界面自上而下四块：

| 区 | 内容 |
|---|---|
| 输入（两个都要给） | ① 炮孔数据库 Excel ② 综合图 DWG ③ 平台 / 日期（从文件名自动识别，可手改）④ 输出目录 |
| 参数 | 外推 / 连接半径 / 最小块段 / 接综合图 / **贴合综合图** / 孤立组最少孔数 / 外轮廓兜底k；**精确模式轮廓文件**（.3ds，分号分隔，可多选）；按钮：**存为该平台默认** / **存为该炮区** / **刷新参数** |
| 主按钮 | **一键出三件套** / 打开输出文件夹 / 批量跑整个目录… / 并入综合图（副本）… / 用人工图标定本炮区… / 确认替换综合图原件… |
| 自查按钮 | **查看参数台账** / **跑一键验收（全量）** / **快检** / **打开验收报告** |

后面还有两个勾选：**转 DWG 2010**（需本机 AutoCAD；失败就留 DXF）、**圈完顺手并入综合图副本**。

**支持拖拽**（`tkinterdnd2`，可选）：数据库 Excel → 数据库栏（并自动识平台/日期、找综合图、填输出目录）；
名字带"综合"的 DWG → 综合图栏；其它 DWG → 人工圈矿图（标定按钮直接用）；`.3ds` → 精确模式轮廓栏；
文件夹 → 输出目录。

**.3ds 两种用法**（参数区那个勾选框）：

* **勾上 = 人工圈矿模式**（`manual_blocks`）：你在 3DMine 里自己圈好，**一条闭合线 = 一块**，
  程序不圈矿、只算量出图出报告（`strip.blocks_from_outline_files`）；
* 不勾 = 精确模式（`outline_files`）：整条当**矿界**，界内按品位档再分块。

两者都能走命令行：`python core\run_strip.py <库.xls> <平台> <炮区> <输出目录> <综合图.dwg>
[--manual-blocks a.3ds;b.3ds] [--outline a.3ds]`。

### 2. 命令行（等价）

```
python core\run_strip.py "<数据库.xls>" <平台> <炮区> "<输出目录>" "<综合图.dwg>"   # 一个炮区出三件套
python core\run_batch.py  "<父目录>" "<综合图.dwg>" "<输出目录>" [--full]          # 批量 + 横向汇总
python core\dxf2dwg.py    "<…矿块图.dxf>"                                        # DXF → DWG 2010（AutoCAD COM）
python core\merge_to_composite.py "<综合图.dwg>" "<…矿块边界线.3ds>"               # 并入副本 + 预览
python core\apply_merge.py "<…_并入1008.dwg>" [--dry-run]                        # 确认替换原件（先备份）
python core\merge_status.py "<父目录>" "<综合图.dwg>"                             # 哪些炮区还没并进综合图
python core\calibrate.py <炮区> "<人工圈矿图.dwg>" --platform <平台> [--extrude 3 4 5] [--by-volume] [--write]

python _probe\accept_all.py [平台…] [--quick]      # ★ 一键验收（改代码前后各跑一次）
python _probe\selftest.py [平台…]                  # 圈矿闸门（两档）
python _probe\report_check_all.py [平台…]          # 报告口径回归
python _probe\dxf_check.py <平台> <炮区> --fresh    # 成果图实体自检
python _probe\params_report.py [平台…]             # 参数台账（谁覆盖了什么、依据是什么）
```

| `sample_data\output\` | 评审图与中间产物（`对账_*`、`GUI跑通_*` 已在 `.gitignore` 里，可随时重跑） |

| `口径确认记录.md` | 所有已确认口径（算量 / 矿界 / 分块 / 图上要素 / 参数依据） |
| `使用说明-一键出三件套.md` | 操作手册（输入、产出、参数、故障提示） |

双击就能用的三个 `.bat`：

| .bat | 作用 |
|---|---|
| `启动二次圈矿工具.bat` | 开 GUI（pythonw，无控制台窗口） |

### 2.1 `core\` 主要模块

| 模块 | 作用 |
|---|---|
| `pipeline.py` | **一个炮区的完整流程**（单一入口）：分档 → 孤立组 → 每带矿界 → 分块定档 → 体号重排；两种分块模式 `chain`（整带一条矿界，3940）与 `clusters`（一簇一块、簇间留白，3960）；支持精确模式 `outline_files` |
| `strip.py` | 矿界算法：分左右链、局部法向外推（细长孔簇 `mitre_limit=1.5`，避免锐角尖刺）、端部闭合（`end_pair_beyond`：只认端外无品位孔）、与综合图**贴合**（`join_to_composite` / `seam_join_m`）、自检修补、分簇、块内 Voronoi 算量、**断片窄走廊连通 `connect_ring_parts`**、**矿块轮廓抽稀/圆滑 `simplify_block_outline` / `smooth_block_outline`**、`ring_from_outline_files`（精确模式拼人工画的矿界） |
| `deliver.py` | 三件套生成：报告 xlsx / 报告 png（含品位统计行）/ 成果图 DXF（十字、引线、工程号、品位、1 m 方格、网格小字、矿块号 + 避让、**矢量报告表 LINE+TEXT**）/ .3ds |
| `make_database.py` | 从坐标 TXT + 粘贴品位表生成 3DMine 炮孔数据库：`.xls`（定位表/测斜表/pit_blast）+ `.mdb`（套 `assets\3dmine_template.mdb` 空库模板，保留 config/style/constraint 元数据） |
| `params.py` | 参数三层解析：全局默认 → `platforms[<平台>]` → `blasts["<平台>-<炮区>"]`；`block_simplify_m=0.3`（抽稀）、`block_smooth_m=0.5`（圆滑）、`merge_gap_m=4.5`（接综合图） |
| `oreblocks.py` | 读库（xls/mdb）与算量口径（`gradeLenght`、单元体积、容重、品位加权） |
| `composite.py` | 综合图只读扫描（AutoCAD COM，结果缓存 json）+ 与历史矿块合并；只并**直接相接**的历史块，不链式吞并；接缝圆角闭合 |
| `run_strip.py` / `run_batch.py` | 单炮区 / 批量入口（中文故障提示 + `运行记录.txt`） |
| `calibrate.py` | 一键标定：扫人工图 → 贪心搜"外推 + 左右链" → 写 `blasts["<平台>-<炮区>"]` |
| `dxf2dwg.py` / `merge_to_composite.py` / `apply_merge.py` / `merge_status.py` | DWG 2010 转换 / 并入副本 / 确认替换（先备份、可回退）/ 并图状态 |
| `gradecuts.py` / `rules.py` / `ring_from_parts.py` | 品位界限通用识别 / 1008 的端部配方 / 由人工分段线拼环（精确模式的前身） |

## 三、参数三层结构

`core/params.py` 按 **全局默认 → 平台层 → 炮区层** 依次覆盖，都写在 `圈矿参数.json`：

```json
{
  "extrude_m": 3.0,                                   ← 全局默认
  "platforms": { "3960": { "extrude_m": 2.0, "ring_mode": "clusters" } },
  "blasts":    { "3940-1003": { "extrude_m": 2.5, "chain_left": ["P2","P3"] } }
}
```

常用键：

| 键 | 含义 | 当前值 |
|---|---|---|
| `extrude_m` | 外推距离(m) | 全局 3.0；3960 平台层 2.0；个别炮区 2.5~9.0 |
| `seam_join_m` | 与综合图"贴合对齐"的距离(m)，0 = 关 | 全局 0.5；3960 多数炮区设 0 |
| `zone_link_m` | 孤立孔连接半径(m) | 15 |
| `min_fragment_m2` | 最小块段(m²)，小于它并入邻块 | 40 |
| `isolated_min_holes` | 孤立小组最少几孔才单独圈 | 3940 = 3，3960 = 2 |
| `ring_mode` | `chain`（整带一条矿界）/ `clusters`（一簇一块） | 3940 = chain，3960 = clusters |
| `cluster_exact` / `cluster_same` / `cluster_solo` / `cluster_exclude` | 人工指定分簇（逐块对账得来） | 见 3960 各炮区 |
| `chain_left` / `chain_right` / `chain_exclude` | 人工指定左右链（贪心标定得来） | 3940 的 1003/1004/0915 |
| `ring_alpha_k` | >0 时并上"矿孔外轮廓+外推"兜底（宽/弯矿带） | 1004 = 1.5 |
| `end_pair_beyond` | 端部只认"端孔之外"的无品位孔取中点（用户规则） | 全局 true；3960-0919 = false |
| `outline_files` | **精确模式**：人工导出的矿界 .3ds 路径列表，填了就照它出图 | 默认空 |

看某个炮区到底被覆盖了什么、依据是什么：`python _probe\params_report.py [平台]`
（或 GUI 的"查看参数台账"）。

## 四、验收基准在哪、怎么复现

* 人工图扫描结果：`_probe\manual_<平台>-<炮区>_c.json`（`scan_manual_retry.py` 只读扫出来的）；
* 人工报告合计体积：`_probe\manual_volumes.json`（键 `<平台>-<炮区>`）；
* 取基准统一走 `_probe\baseline.py`；**3940 以人工报告为基准，3960 以人工图算为基准**
  （3960 的报告与图本身对不上，用户 2026-10-13 定"以图为准"）。

跑 `python _probe\accept_all.py` 会打两档（常规 / 严格）结果并写 `验收报告.md`：

* 常规档达标线：3940 IoU ≥0.75 且体积 ±20%（1008 另定 ≥0.90 / ±5%）；3960 IoU ≥0.35 且体积 ±30%；
* 严格档只报数不设闸门（它的分数天然低——综合图里混着当日的块）。

## 五、加一个新平台（如 3970）要做什么

1. **试跑**：`python core\run_strip.py "<新平台数据库.xls>" 3970 <炮区> "<输出目录>" "<新平台综合图.dwg>"`——不用改代码；
2. **标定**：拿该炮区的人工圈矿图跑 `python core\calibrate.py <炮区> "<人工图.dwg>" --platform 3970 --extrude 3 4 5 --by-volume --write`（`--write` 才落盘，写进 `blasts["3970-<炮区>"]`）；
3. **核对**：把人工图扫描成 `_probe\manual_3970-<炮区>_c.json`（`scan_manual_retry.py`），把人工报告合计体积填进 `manual_volumes.json`，再跑 `accept_all.py 3970`；
4. **整平台调参**：整个平台共有的（外推、模式）写 `platforms["3970"]` 层，别逐个炮区写。

## 六、改代码的规矩

1. 任何算法改动，**先跑 `python _probe\accept_all.py`，全绿再提交**；退化就退回来；
2. 口径有疑问或不确定**先问用户**，不要自己拍数值（本项目所有阈值都是拿人工图标定或被用户拍板）；
3. 真实矿山数据（`北部山头3940平台2026\`、`北部山头3960平台2026\`）**只读、不挪不改**；
   综合图只用 AutoCAD 只读扫描；"并入综合图"一律先出副本，替换原件必须人工确认（有备份可回退）；
4. **不要动 3DMine 安装目录**（曾因改动导致 3DMine 打不开）；
5. 参数只在 `圈矿参数.json` 里生效；`params.py` 的 `DEFAULTS["blasts"]` 故意留空（
   历史上那里留过只有日期的旧键，从来不生效却会被统计脚本当成平台）。
