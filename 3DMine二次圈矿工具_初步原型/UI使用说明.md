# 二次圈矿智能工作台 · UI v2 使用说明

> 面向：露天矿山地质技术人员。这份只讲"怎么用"；设计与实现见 `client/ui_v2/README.md`，
> 功能与脚本的对应关系见 `UI功能接入清单.md`。

## 一、怎么启动

| 方式 | 操作 | 说明 |
|---|---|---|
| **新版界面（源码）** | 双击 `启动二次圈矿工具_v2.bat` | PySide6 界面，需要本机有 Python + PySide6 |
| **免安装 exe（推荐）** | 双击 `dist\二次圈矿智能工作台\二次圈矿智能工作台.exe` | 不用装 Python；启动约 3~8 秒；首次运行在 exe 旁建 `data\` |
| **单文件 exe** | 双击 `dist\二次圈矿智能工作台.exe` | 只有一个文件、方便拷贝；**每次启动要解包，冷启动明显慢**（本机实测 6~8 分钟，正常机器约 20~60 秒） |
| **旧版界面** | 双击 `启动二次圈矿工具_旧版.bat` | 原来的 Tkinter 界面，功能完全保留，可随时回退 |
| 命令行 | `python client\ui_v2\app.py` | 开发/排错用 |

> `data\` 目录是 exe 版的"可写根目录"：`圈矿参数.json`、`excel_tools\config\grade_profiles.json`、
> `.ui_state.json` 都在里面。升级 exe 时**别删这个目录**，参数就还在。

新版需要 PySide6：`<你的Python> -m pip install PySide6`。缺依赖时启动脚本会明确提示并告诉你命令，
不会静默失败 —— 也可以先用旧版继续干活。

## 二、界面结构

```
┌────────────┬──────────────────────────────────────────────────────────┐
│ 侧边导航    │ 顶栏：页面名 / 说明 ｜ 项目 · 平台 · 矿段 · 任务状态 ｜ ⚙ │
│ 工作        ├──────────────────────────────────────────────────────────┤
│  工作台     │                                                          │
│  单炮区…    │                     页面工作区（可滚动）                   │
│  批量处理   │                                                          │
│ 数据        │                                                          │
│  人工圈矿…  │                                                          │
│  综合图管理 │                                                          │
│  Excel…     │                                                          │
│  数据库生成 │                                                          │
│ 系统        │                                                          │
│  参数管理   │                                                          │
│  验收与诊断 │                                                          │
│  系统设置   │                                                          │
└────────────┴──────────────────────────────────────────────────────────┘
```

* 窗口默认 1440×900，最小 1280×720；跟随系统 125%/150% 缩放。
* 顶栏四个小标签始终显示：当前项目目录、平台（含日期）、矿段（自动识别结果显示成"自动 → 金斗山"）、
  后台任务状态（有任务在跑时会变成"运行中：xxx"）。

## 三、日常工作怎么走

### 1. 单炮区二次圈矿（最常用）

1. **① 输入数据**：点「浏览」选炮孔数据库 Excel —— 平台、日期、综合图、输出目录会**自动带出来**；
   也可以把文件直接拖进任一输入框（拖文件夹 = 输出目录）。
2. **② 圈矿模式**：三选一
   * ① 自动圈矿：程序自己分档、圈界、分块；
   * ② 人工圈矿：选人工画的 `.3ds`（一条闭合线 = 一块），只算量出图；
   * ③ 精确模式：选人工 `.3ds` 轮廓当整条矿界，界内再按品位分档。
   炮区文件夹里有 `.3ds` 时会**自动取用并把模式切好**（与旧版一致）。
3. **③ 参数配置**：常用 6 项直接显示，"高级参数"折叠着（外推、连接半径、最小块段…）。
   每个参数名后面的灰字告诉你它来自 **全局默认 / 平台 xxx / 炮区 xxx**。
   改完点「存为平台默认」或「存为当前炮区」，写回的就是 `圈矿参数.json`，优先级没变。
4. **④ 执行**：勾选"转 DWG 2010""并入综合图副本"（默认都勾），点 **一键出三件套**。
   右侧日志实时滚动，进度条按"第 1/2/3 步"推进；跑完右上「成果文件」列出报告/图片/成果图/边界线，
   点小箭头直接打开。

> 顶部右侧「打开输出目录」随时可用；日志可"另存日志"。

### 2. 批量处理

1. 选"单日数据父目录"（里面每个子目录 = 一天炮区）与共用的综合图；
2. 点「扫描炮区」→ 表格列出每行的平台/炮区/数据库/综合图；
3. 勾选要跑的行 → 点 **开始批量圈矿**：一行一行跑，状态（待执行/运行中/完成/失败）、开始/完成时间、
   说明列实时刷新；点某一行可在下方看**这一行的日志**；
4. 「中止队列」= 不再启动后面的（当前这条会跑完）；「重试失败项」= 把失败的重新排队。

原版的"一次跑完并出横向汇总表"仍然保留：**跑原批量流程（含汇总表）** → 结果在 `_批量汇总\`。

### 3. 人工圈矿与参数标定

左边是人工结果、右边是自动结果，下方是对比表（矿块数、面积、体积、重量、品位、金属量）。

1. 选数据库 + 人工圈矿图 DWG；
2. 「读取人工图块」→ 只读扫描人工图（块数 / 面积）；
3. 「跑一次自动圈矿」→ 用当前参数跑一遍，回填右侧数字；
4. 「自动标定（演练）」→ 打印推荐的外推距离与左右链，**不写参数**；
5. 确认无误后「自动标定并写入参数」→ 会弹二次确认，只改 `blasts[平台-炮区]` 这几个键。

### 4. 综合图管理

* **只读扫描**：看综合图里已有的历史矿块数与面积；
* **生成本次合并副本**：选当天的 `.3ds` → 出 `…_并入<日期>.dwg` + `_预览.png`，**原件不动**；
* **替换原件**（危险）：选副本 → 二次确认 → 先把原件改名备份（`原名_原版_时间戳.dwg`）再覆盖。

### 5. Excel 数据工具

* **炮孔报告汇总**：加文件/加目录 → 选汇总方式（total/detail）与品位分级 → 开始汇总；
  选项与原工具一致（追加原始报告、公式/数值、标题）。
* **单日数据并入总表**：选单日目录（总表目录留空自动定位）→ 先「预演（不写盘）」核对计划 →
  「正式并入」（判重/备份/矿块图同步默认全开）→ 需要时「还原备份」。

### 6. 炮孔数据库生成

坐标 TXT + 粘贴品位表 → 「解析预览」看匹配情况（缺品位/多出/冲突会直接标红）→ 填平台/日期/台阶高度 →
「生成 .xls / .mdb」。字段、模板、孔深取整口径与原工具完全一致。

### 7. 参数管理 / 验收与诊断 / 系统设置

* **参数管理**：三层结构一目了然，"覆盖关系"表逐参数显示 全局/平台/炮区 的值与最终来源；
  「参数台账」跑原有 `params_report.py`。
* **验收与诊断**：一键全量验收 / 快速验收，逐项状态（通过 / 没通过 / 未执行）+ 完整日志 + 打开验收报告。
* **系统设置**：环境信息、路径、打开数据目录、重建默认配置（先备份）、清空最近记录、
  **打开旧版界面**（新界面出问题时的回退入口）。

## 四、几条要记牢的规矩

1. **数据只读**：扫描综合图、读人工图都是只读；合并只出副本；替换原件一定先备份。
2. **参数不会被界面初始化清空**：界面只在你点保存时写 `圈矿参数.json`，且只 update 对应层级。
3. **矿段（品位分级）只有一份配置**：`excel_tools\config\grade_profiles.json`。
   界面里的图例颜色、报告档位都来自它；不要在新界面里另设阈值。
4. **长任务都在后台**：圈矿、DWG 转换、批量、验收都是独立进程，界面不会卡死；
   关窗口时若还有任务会提示，确认后才终止。
5. **成果文件命名不变**：`<平台>平台 <日期>炮孔数据报告.xlsx/.png/.xls`、
   `…二次圈矿矿块图.dxf`、`…矿块界线_2010.dwg`、`…矿块边界线.3ds`，与旧版一致。

## 五、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 启动提示缺 PySide6 | 按提示 `python -m pip install PySide6`，或先用 `启动二次圈矿工具_旧版.bat` |
| 第 2 步 DWG 转换失败 | AutoCAD 没起来/停在对话框；DXF 已保留，可在 CAD 里另存 2010，或取消勾选该步 |
| 第 3 步并入副本失败 | 同上（要读综合图）。副本文件其实已生成，CAD 空闲后单独重跑这一步 |
| 「读取人工图块」失败 | 人工图扫描依赖 AutoCAD；没有 AutoCAD 时该功能不可用，但自动圈矿照常 |
| 验收里有项目"没通过" | 先看日志最后几行；多数是缺数据目录（`D:\WK\N CRT\…`）或 AutoCAD 未开 |
| 换机器后参数是空的 | 源码版：参数/分级在 `圈矿参数.json` 与 `excel_tools\config\`，升级时一起带走；exe 版：复制 exe 旁的 `data\` |
| 单文件 exe 启动特别慢 | 单文件每次启动都要解包到临时目录（杀毒软件还会再扫一遍）。日常用 `dist\二次圈矿智能工作台\` 目录版，秒开 |
