# 3DMine 二次圈矿工具 —— 可再现脚本流水线

输入任意 3DMine 格式炮孔数据库 Excel（定位表 + 测斜表 + blast 品位表，直孔），
自动产出 3 份成果，全部可重复运行：

| # | 成果 | 文件 | 说明 |
|---|------|------|------|
| 1 | DWG2010 成果图 | `output\3940平台 1004二次圈矿矿块图_3块版_2010.dwg` | 图面风格对齐人工图：炮孔十字+引出线+完整工程号（h=0.4 色138）、品位大字（h=0.7 按分级着色）、方格中心品位小字、彩色矿块边界（无填充）、矿块号引出线分离、报告图片、2010 格式（AC1024） |
| 2 | 炮孔数据报告 | `output\3940平台 1004炮孔数据报告.xlsx` + `output\1004_macro\1004炮孔数据报告_v4.png` | 按矿块汇总体积/重量/平均品位/金属量，含分级小计、合计、炮孔统计（DWG 中以图片形式插入） |
| 3 | 矿块边界线文件 | `output\1004_macro\3940平台 1004矿块边界线.3ds` | 3DMine_2009 文本格式，可导入 3DMine 显示矿块边界 |

## 一键运行

```bash
python run_1004_pipeline.py [炮孔数据库Excel路径]
```

不传参数时使用默认 1004 数据（`D:\WK\N CRT\北部山头3940平台2026\7、单日数据\北部山头3940平台-1004\1、3940平台 炮孔数据库1004.xls`）。

## 流水线三步（每步独立可复用）

| 步骤 | 脚本 | 输入 → 输出 | 功能 |
|------|------|-------------|------|
| Step1 圈矿算量 | `output\_macro_prep_1004_v61.py` | Excel → `output\1004_macro\1004_blocks.json` | 读炮孔库（31孔）→ 按品位分级（0.5-1 / 1-1.5 / 1.5-3 / ≥3）Voronoi 圈连 → 相邻可采性差的小块合并（如 2/3/5/6 号按 1.5-3 整体、7/8 号圈一起）→ 矿块品位按"块内全部孔（含废孔）面积加权"计算 → 体积（台高10m）/重量（容重2.7）/金属量 → 1m 网格线 |
| Step2 生成图件 | `output\_make_1004_dwg_v4.py` | json → DXF + 报告PNG + .3ds | ezdxf 生成 R2010 DXF（图层/样式/颜色对齐人工图：CN_SHX=txt.shx+gbcbig.shx、CN_TTF=simsunb.ttf）；报告表格 PNG；.3ds 边界线（GBK） |
| Step3 转 DWG2010 | `3dmine_scripts\_conv_v3.py` | DXF → DWG(AC1024) | 调用本机 AutoCAD 2023 COM：清进程→启动→轮询→Open→SaveAs(枚举48=AC1024/R2010)→校验文件头 |

## 换数据库

修改三步脚本顶部的 `XLS` / 输出路径变量为新的炮孔库路径即可。
矿块合并规则、品位档、配色、文字高度等参数均集中在脚本顶部，可调。

## 关键技术参数（对齐人工图）

- 品位档配色：0.5-1 青(4)、1-1.5 蓝(5)、1.5-3 红(1)、≥3 黄(2)、废孔灰(8)
- 图层：矿块边界按品位档命名（`0.500-1.000` 等）、网格 `爆区方格网`、炮孔 `钻孔`、矿块号 `线条`、品位文字 `点`、报告 `报告`
- 炮孔：十字（臂长1.0m，按品位着色）+ 引出线（右上3.2m）+ 完整工程号（`BS-3940-1004-P1`，h=0.4，色138，simsunb）+ 品位大字（h=0.7 分级色）
- 品位小字：方格中心（单元左下角+0.5,+0.5），h=0.2，按分级色
- 矿块号：MTEXT h=5.0，矿块外 + 各自引出线（起点在各自矿块边界，不重叠）
- 矿块无斜线填充；中文用 gbcbig.shx / simsunb.ttf（避免问号）

## 常见问题

- **AutoCAD COM 连接失败/挂起**（`Dispatch("AutoCAD.Application")` 无响应）：多为 acad 残留进程或冷启动慢。
  1. 任务管理器结束所有 `acad.exe`
  2. 重新运行 `run_1004_pipeline.py`
  3. 仍失败时用 GUI 兜底：手动打开 AutoCAD → 文件→打开 `output\1004_macro\3940平台 1004二次圈矿矿块图_3块版_full.dxf` → 文件→另存为 → 文件类型选 `AutoCAD 2010/LT2010 图形 (*.dwg)` → 保存到 `output\3940平台 1004二次圈矿矿块图_3块版_2010.dwg`
- **报告图片占用**：若 `1004炮孔数据报告.png` 被其他程序打开无法写入，脚本自动改用 `_v4.png` 后缀
- **3DMine 底座**：宏（PyMacro/VBA）需正式授权版；免安装版宏不可用，故成果图件由 Python 生成 + AutoCAD 转换，数据口径与人工流程一致
