# 交付说明（拿这个目录就能用）

## 一、怎么开始用（三步）

1. **双击 `首次运行检查.bat`** —— 检查 Python / 依赖包 / 数据目录 / 参数文件 / 输出目录 / AutoCAD，
   最后一行给出 `结论：可以直接用 ✓` 或列出"必须解决"的项（每项都写了怎么修）。
2. **双击 `启动二次圈矿工具.bat`**（桌面上也有一个 **`二次圈矿工具`** 快捷方式，指向它）
   —— 打开图形界面。
3. 在界面上：选**炮孔数据库 Excel** → 选该平台的**综合图 DWG** → 填**平台/日期**
   （从文件名自动识别，可手改）→ 给一个**输出目录** → 点 **一键出三件套**。

产出（输出目录里）：

| 文件 | 内容 |
|---|---|
| `<平台>平台 <日期>炮孔数据报告.xlsx` / `.png` | 分档列块号、体积、重量、平均品位、金属量（百克）+ 炮孔品位统计行 |
| `<平台>平台 <日期>二次圈矿矿块图_2010.dwg`（失败则留 `.dxf`） | 彩色矿块、1 m 方格 + 格心品位、炮孔十字 + 工程号 + 品位、矿块号引线、报告图片 |
| `<平台>平台 <日期>矿块边界线.3ds` | 每个矿块一条闭合字符串并带体名，格式对齐 3DMine 选择集 |
| `运行记录.txt` | 本次的时间/耗时/输入/当时生效的全套参数/产出清单/完整日志 |

## 二、另外三个双击入口

| 双击 | 作用 |
|---|---|
| `跑验收.bat` | 跑全套验收（约 3 分钟：圈矿闸门两档 + 报告口径 + 成果图实体自检 17 个炮区 + 精确模式），完了自动打开 `验收报告.md`；加 `--quick` 是快检 |
| `看参数台账.bat` | 列出"全局默认 → 平台 → 炮区"三层参数，每个覆盖值都带依据；没写依据的打 ⚠ |
| `首次运行检查.bat` | 换机器/怀疑环境问题时先跑它 |

## 三、需要什么环境

* Windows + **Python 3.10+**（本机是 `C:\Users\Administrator\AppData\Local\Programs\Python\Python313`）；
* 依赖：`numpy scipy shapely matplotlib ezdxf openpyxl xlrd`（缺哪个 `首次运行检查.bat` 会直接告诉你 `pip install <包>`）；
* **AutoCAD 可选**：只有两件事用它——① 只读扫描综合图里的历史矿块 ② DXF 另存为 DWG 2010。
  没有它照样出报告和成果图（留 DXF，手工另存 2010 即可）。

## 四、界面上的按钮都干什么

| 按钮 | 作用 |
|---|---|
| **一键出三件套** | 上面那条主流程 |
| 批量跑整个目录… | 选一个"每个子目录是一天炮区"的父目录，一次跑完并出汇总表/汇总图 |
| 并入综合图（副本）… | 把某天的边界线并进综合图**副本**（原件不动），出预览图 |
| 确认替换综合图原件… | 弹窗确认后：原件改名备份 → 副本顶上；可回退 |
| 用人工图标定本炮区… | 给一张人工圈矿图，自动标定该炮区的"外推距离 + 左右链"并写进参数 |
| 查看参数台账 / 跑一键验收 / 快检 / 打开验收报告 | 自查四件（见上面第二节） |
| 参数区 | 改完点 **存为该平台默认** 或 **存为该炮区**；"精确模式轮廓文件"框可直接导入人工画好的矿界 .3ds |

## 五、出问题看哪儿

1. 输出目录里的 **`运行记录.txt`**（含当时参数与完整日志）；
2. **[故障与排查.md](故障与排查.md)**：按症状查（输入类 / 圈矿结果 / 出图要素 / 综合图 / 验收）；
3. **[验收报告.md](验收报告.md)**：最近一次全量验收的结论（带代码版本）；
4. 口径上的疑问看 **[口径确认记录.md](口径确认记录.md)**（唯一依据）。

## 六、安全边界（重要）

* `北部山头3940平台2026\`、`北部山头3960平台2026\` 等**真实矿山数据只读**——程序从不改写它们；
  "并入综合图"一律先出**副本**，替换原件必须你人工确认（有备份可回退）。
* 不要手改 `3DMine` 安装目录里的任何东西（历史上改坏过一次）。
* 想回退到某个版本：这个目录是 git 仓库，`git log --oneline` / `git checkout -- <文件>` 即可。
