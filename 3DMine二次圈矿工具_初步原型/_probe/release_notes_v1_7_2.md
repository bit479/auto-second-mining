# v1.7.2 —— `.bak` 统一收进 `bak/` 子文件夹

用户反馈：程序产生的 `.bak` 和正常文件混在一个文件夹里太乱。

## 改动

* 每个 `.bak` 所在文件夹下自动建一个 **`bak\`** 子文件夹；
* 新生成的备份**直接写进 `bak\`**：
  * 年度总表：`bak\<原名>_并入<日>.bak`；
  * `6、…矿块图`：`bak\<原名>.bak`；
  * 还原前的保护备份：`bak\<原名>_还原前<时间>.bak`；
* 运行"一键出图 / 并入总表 / 并入综合图"时，会把所在文件夹第一层已有的 `.bak`
  一并收进 `bak\`（不递归、不动子文件夹里的文件）；
* 同名冲突自动加 `-2`、`-3`，绝不覆盖；被 CAD 占用移不动的只提示，不中断流程；
* "确认替换综合图"生成的 `<原名>_原版_时间.dwg` 是 `.dwg` 备份，不是 `.bak`，保持原位。
