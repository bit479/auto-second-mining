# v1.7 —— 图上三处修正（小片归属 / 标注引线 / 手机端表格）

这一版只改成果图，圈矿算法与算量口径不动。

## 1. 人工画线切出来的小片不再丢

1004 左下角青块与红块交界处，原来有 5.85 m² 被当成"无孔边角料"丢掉了，
图上就出现一个小缺口。现在**不丢**，并入相邻的最大块——这块 5.85 m² 归入青色
0.5-1 档块，该块面积 772.90 → **778.75 m²**，与"保留为青色矿块"的要求一致。

## 2. 矿块号引线从矿块中心出发

以前引线起点是"矿块边界上离文字最近的点"，经常正好落在两块交界处。
现在起点取**矿块主体（最大那片）的最深内部点**（`polylabel`），
即使矿块由多片组成，也不会落到 0.09 m² 的细条里。

## 3. 报告表改成矢量，手机 CAD 也能看

以前报告表是外部 PNG 的 **IMAGE 参照**，手机端 CAD 看图王只显示 png 文件路径。
现在表格的标题、表头、每行数字、框线全部是图内的 **TEXT + LINE** 实体，
不依赖任何外部图片；PNG 仍单独生成，供报告/预览使用。

表格内容与原来一致：类型 / 体号 / 体积 / 重量 / 平均品位(Au) / 金属量（百克），
含小计、合计，以及 ≥3、1.5-3、1-1.5、0.5-1、<0.5 的炮孔数统计。

## 4. 顺手修的一个提示

目标 DWG 被 CAD/看图软件占用时，程序会另存为 `..._2010_new.dwg`。
以前日志只说"成功"，用户打开旧文件会以为没改；现在日志会明确写出新文件名。
