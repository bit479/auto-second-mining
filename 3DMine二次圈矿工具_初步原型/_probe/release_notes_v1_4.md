## 二次圈矿工具 v1.4

### 单日并入总表：顺手把二次圈矿矿块图复制进「6、」文件夹

以前并入完数据，矿块图还得手工往 `6、` 文件夹里拖一次、再改个名。现在**跟并入一起做**，
不用单独点：

```
7、单日数据\北部山头3940平台-1008\5、 北部山头3940平台二次圈矿矿块图1008.dwg
        ↓  复制 + 去掉文件名开头的「N、」前缀
6、北部山头3940平台二次圈矿矿块图\北部山头3940平台二次圈矿矿块图1008.dwg
```

（`5、` 后面那个空格也一起去掉；3940/3960 的源文件名带空格、3970 的不带，两种都认。）

**判重做得跟并入部分一样"反复跑也安全"**：

| 目标文件夹里的情况 | 行为 |
|---|---|
| 没有同名图 | 直接复制 |
| 有同名图、逐字节相同 | **跳过**（不动它） |
| 有同名图、内容不同 | 先备份成 `<原名>.bak` 再覆盖（沿用文件夹里既有的 `1003.bak` 习惯） |

不想让它参与：命令行加 `--no-map`，或界面取消勾选「同时把二次圈矿矿块图复制进 6、文件夹」（默认勾上）。

界面上的表现形式（单日并入页）：

```
类型                    单日文件                                   总表文件
炮孔数据库 (.xls)       1、3940平台 炮孔数据库1008.xls            1、北部山头3940平台 炮孔数据库-2026.xls
炮孔数据库 (.mdb)       2、3940平台炮孔数据库1008.mdb             2、北部山头3940平台炮孔数据库-2026.mdb
炮孔数据报告 (.xlsx)    3940平台 1008炮孔数据报告.xlsx            3、北部山头3940平台炮孔数据报告-2026综合.xlsx
二次圈矿矿块图 (.dwg)   5、 北部山头3940平台二次圈矿矿块图1008.dwg  6、北部山头3940平台二次圈矿矿块图(文件夹)
```

`--restore` 还原总表时，如果给了 `--day`，矿块图的 `<原名>.bak` 也一起还原。

### 怎么用

1. 解包，双击 **`启动二次圈矿工具.bat`**（窗口标题会显示 **v1.4**，一眼看出跑的是哪版）；
2. 主界面下方「Excel 工具」→ **单日数据并入总表…**，选那天的单日目录 → **开始**；
3. 或命令行：`python excel_tools\main.py --daily --day-dir "…\7、单日数据\北部山头3940平台-1008"`
   （加 `--dry-run` 只看不写）。
