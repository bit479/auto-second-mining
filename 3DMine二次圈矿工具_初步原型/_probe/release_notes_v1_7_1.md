# v1.7.1 —— 报告表改为 Excel 默认风格

用户反馈：插入 DWG 的炮孔数据报告表"行高有些高了"，要求改成 Excel 默认风格、所有文字居中。

## 改动

* **行高**：`2.2 m → 1.3 m`（约原来的 59%），主表与品位统计表同步；
* **文字**：标题、表头、数据、小计、合计全部水平 + 垂直居中；
  Excel 报告（.xlsx）的数据单元格也同步改成居中；
* **边框**：细线（lineweight 13），灰色（色号 8），与 Excel 默认网格线的观感一致；
* **标题**：报告表标题、 "炮孔品位统计（孔数）" 小标题都跨整表居中，不再左对齐。

表格仍然是矢量 TEXT + LINE，不引用外部图片，手机 CAD 看图王可正常显示。
