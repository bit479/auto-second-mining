## 二次圈矿工具 v1.5

### ① 人工画的 .3ds **没闭合**也能出图

以前程序要求每条线都首尾闭合。现在按你 10-18 给的那份（`N CR 1018未闭合线.3ds`：1 条闭合矿界 +
3 条**开口**品位线）改成：

* **闭合线 = 矿界**；
* **开口线 = 分块切线**：两端沿**各自末端那段的方向**自动外延 12 m 切穿矿界，逐条把矿界切开，
  切出来的每一片 = 一块；
* 切出来的**细边角**自动丢掉（面积 < max(1 m², 矿界 0.5%)，或"没孔心且 < 最大块的 30%"）；
* 环里含环时外层减掉内层（防重复算量）；只给开口线时按"首尾相连"各成一块。

实测（3940-1004 炮孔库 + N CR 1018 那套）：

| | 各块面积 m² |
|---|---|
| 你的闭合版（4 条闭合线） | 76.1 / 77.7 / 111.9 / 772.9 |
| 本工具用**未闭合版**切出来 | 76.1 / 71.8 / 111.9 / 772.9 |

（第 2 块差 5.9 m²：你的"闭合版"那条线除首尾相连外还多画了几个折点，不是同一条几何；
程序对开口线只能用"沿末端方向直线延伸"这一种确定性解释。）

### ② 交付多了两样（照你列的那套文件）

* **`.xls` 报告**：`<平台>平台 <日期>炮孔数据报告.xls`（与 xlsx 同内容，给只认 .xls 的流程）；
* **`炮孔数据报告分表/`** 文件夹：每块一份 xlsx，3DMine 分表版式
  （`3DMine 炮孔数据库报告` 标题 + 类型/体号/体积/重量/平均品位(Au)/金属量 + 该块 + 小计 + 总计）。

所以现在输入 **炮孔数据库 Excel + 一个（可以没闭合的）.3ds**，输出是：
`炮孔数据报告.xlsx/.xls/.png`、`炮孔数据报告分表/`、`二次圈矿矿块图.dxf`（可转 DWG 2010）、
`矿块边界线.3ds`、`运行记录.txt`。

> `.mdb` 是 3DMine 自己导出的库（含它的元数据表），本工具不生成——你输入目录里本来就有
> `2、3940平台炮孔数据库1004.mdb`。如果确实要"从 Excel 生成 mdb"，告诉我再做。
