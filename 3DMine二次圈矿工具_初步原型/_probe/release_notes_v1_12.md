## 二次圈矿工具 v1.12

### 生成炮孔数据库：孔深三列统一取整

用「坐标 TXT + 品位表」一键生成 `.xls` / `.mdb` 时，三处孔深以前口径不一致 ——
`.xls` 写 3 位小数（`9.158`），`.mdb` 才取整。现在**统一按整数写**：

| 表 | 列 | 现在 |
|---|---|---|
| 定位表 | 最大孔深 | **整数**，如 `9` |
| 测斜表 | 深度 | **整数**，如 `9` |
| pit_blast | 至 | **整数**，如 `9` |

**坐标 E / N / R 不动**，仍保留 3 位小数。

### 是"真四舍五入"，不是 Python 的 round

这条要特别说明：Python 内置 `round()` 是**银行家舍入**，`round(8.5)` 得 **8**、`round(9.5)` 得 10，
逢 .5 时往偶数靠；跟 Excel / 3DMine 里的四舍五入对不上。所以改用
`Decimal(str(v)).quantize(1, ROUND_HALF_UP)`：

| 设计孔深 | 取整 | 备注 |
|---|---|---|
| 8.500 | **9** | 内置 `round()` 会给 8 |
| 9.500 | **10** | |
| 9.400 | 9 | |
| 9.600 | 10 | |
| 10.000 | 10 | |

### 顺带加的边界检查

取整后变成 **0** 的孔（比如设计孔深 0.4 m，多半是平台高程或台阶高度填错了）
不再悄悄写 0，而是直接报错并点名是哪几个孔：

```
[错误] 这些孔四舍五入后的孔深为 0：BS-3940-0101-P1(0.400)（请检查平台高程/台阶高度）
```
