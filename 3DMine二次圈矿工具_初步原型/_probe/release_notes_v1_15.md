## 二次圈矿工具 v1.15 —— 新版桌面界面「二次圈矿智能工作台」

Tkinter 那一套**原样保留**，另加一套 PySide6 的现代化工作台；两套共用同一批脚本，
算法、Excel 口径、成果文件格式**一律没动**（原生验收 9 大项全量通过）。

### 一、界面

* 左侧导航 + 顶栏状态 + 中央工作区的三栏结构，默认 1440×900，最小 1280×720，跟随 125%/150% 缩放。
* 10 个页面：**工作台 / 单炮区二次圈矿 / 批量处理 / 人工圈矿与参数标定 / 综合图管理 /
  Excel 数据工具 / 炮孔数据库生成 / 参数管理 / 验收与诊断 / 系统设置**。
* 统一 QSS 主题（`#F4F6F8` / `#14263D` / `#2878A5` / `#B87945`），图标全部是内联 SVG 线性图标，
  不依赖外部图片文件；品位分级色一律取自 `grade_profiles.json`，与成果图一致。
* 单炮区页做成流程式四步（输入 → 模式 → 参数 → 执行），三种圈矿模式用卡片选择；
  参数分「基础 / 高级」，每个参数后面灰字标出它来自全局默认 / 平台 / 炮区。
* 批量页是表格 + 队列：状态、开始/完成时间、错误信息逐行刷新，点行看单任务日志，支持中止与重试失败项。
* 所有长任务走独立进程（`QProcess`）：日志实时进日志台，界面不卡；同一任务防重复启动，关窗口前会确认。

### 二、界面与业务的边界

新界面**只调用**原有入口，不复制算法：

| 页面 | 实际调用 |
|---|---|
| 单炮区 / 批量 | `core/run_strip.py`（参数顺序与旧版完全一致） |
| DWG 2010 / 并入综合图副本 | `core/dxf2dwg.py` / `core/merge_to_composite.py` |
| 人工标定 | `core/calibrate.py`（写入前二次确认） |
| Excel 报告汇总 / 单日并入 | `excel_tools/main.py`（total/detail、判重、备份、还原全保留） |
| 数据库生成 | `core/make_database.py`（同一套模板与取整口径） |
| 参数台账 | `core/params_report.py` |
| 验收 | `_probe/accept_all.py`（跑完把逐项状态回填到页面） |

### 三、打包

| 产物 | 说明 |
|---|---|
| `dist\二次圈矿智能工作台\二次圈矿智能工作台.exe` | **免安装目录版（推荐）**：不装 Python，启动 3~8 秒；首次运行在 exe 旁建 `data\` |
| `dist\二次圈矿智能工作台.exe` | 单文件 exe：一个文件好拷贝，但每次启动要解包，冷启动慢（本机实测数分钟） |
| `启动二次圈矿工具.bat` | 默认入口：有 PySide6 走新界面，没有或出错自动回退旧版 |
| `启动二次圈矿工具_旧版.bat` | 旧版 Tkinter 界面（回退用） |
| `打包exe.bat` | 一键重建 exe（`--onedir` 出目录版） |

exe 里的 `data\` 是可写根目录：`圈矿参数.json`、`excel_tools\config\grade_profiles.json`、
`.ui_state.json` 都在这里，升级 exe 时不要删它。

### 五、注意

1. 新界面需要 `PySide6`（源码方式运行时）：`python -m pip install PySide6`；exe 版不需要。
2. 旧 PoC（根目录 `main.py`、`client/prep_generic.py`、`make_dwg_generic.py`）不在新界面链路上，
   也不在"一键出三件套"链路上。
3. 人工标定的左右图形对比目前用的是已有 DXF/PNG 预览，没有做交互式缩放漫游。
