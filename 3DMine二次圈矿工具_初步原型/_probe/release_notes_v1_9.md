# v1.9 —— 从坐标 TXT + 品位表一键生成炮孔数据库

主界面新增 **"从坐标 TXT + 品位表生成 .xls/.mdb…"**，也可以直接把
`BS-3940-0915-P1-P47.txt` 拖进主窗口。

## 输入

* 坐标 TXT：`工程号,,开孔坐标E,开孔坐标N,开孔坐标R`；
* 品位表：从 Excel 直接粘贴（Tab 分隔），或 Markdown 表格；
  程序按 `BS-…` 工程号后面第一个数字取品位。

## 输出

* `1、<平台>平台 炮孔数据库<日期>.xls`
  * `定位表`：工程号 / E / N / R / 轨迹类型=直线 / 最大孔深；
  * `测斜表`：工程号 / 深度 / 方位角=0 / 倾角=-90；
  * `pit_blast`：工程号 / 从=0 / 至=孔深 / Au。
* `2、<平台>平台炮孔数据库<日期>.mdb`
  * 真正的 **Standard Jet DB**；
  * 用 `assets\3dmine_template.mdb` 空库模板生成；
  * 保留 `config_table_3dmine`（18 行）/ `style_table_3dmine`（5 行）/
    `constraint_table_3dmine` 元数据。

## 口径

* 台阶高度默认 10 m：孔底高程 = 平台高程 − 10，最大孔深 = R − 孔底高程；
* `.xls` 写精确孔深（0.001 m）；`.mdb` 按现有 3DMine 库习惯取整到整米；
* 缺工程号、同号不同品位直接报错；多出的工程号提示后忽略；
* 目标 `.xls/.mdb` 已存在时，先备份到同目录 `bak\` 再覆盖。
