## 二次圈矿工具 v1.3

### 把"Excel 处理工具"整合进来了

原来单独的 `D:\WK\N CRT\Excel处理工具` 已经**搬进本项目**（`excel_tools\`，代码、界面、三项自检、
两个 .bat 一起进来），主界面下方多了一块 **"Excel 工具（报告汇总 / 单日数据并入总表）"**：

| 按钮 | 作用 |
|---|---|
| **炮孔报告汇总…** | 打开完整窗口：把若干份 3DMine 分块报告汇总成一份炮孔数据报告（`total` / `detail` 两种口径） |
| **单日数据并入总表…** | 打开完整窗口：把某天的 `xls / mdb / 报告` 三份文件并入年度三份总表（自动识别文件、按工程号判重、写前备份、可还原） |
| **把数据库所在的那天并入总表（预演）** | 不用另开窗口：拿界面上选的数据库所在文件夹当日目录，**只算不写**，结果打在日志区 |
| **正式并入** | 同上但真写进去（先弹窗确认；它自己会把总表备份成 `<原名>_并入<日>.bak`） |

它自己的三项自检也进了"一键验收"（`跑验收.bat`）——现在是 5 大项：
圈矿闸门两档、报告口径回归、成果图实体自检（全炮区）、精确模式自检、**Excel 工具自检**。

> 顺手修了它自检里的一个"假失败"：`test_daily_merge.py` 原来假定那一天还没并进总表，
> 而真实总表里 1008 已经并过了 → 判重让"新增 0 行"，断言就红了。现在两种状态都算通过
> （真并了查行数与逐值一致；已并过查判重与"不产生多余备份"），跑出来 26/26。

### 同时包含前几版的修复

* **成品图严格照你画的 .3ds**（用 .3ds 时矿界原样用：不抽稀、不修补、不并综合图）；
* **成品图不再画综合图那一片灰线**（默认关）；
* **程序自己在炮区文件夹里找 .3ds**（优先"分品位"那份），按闭合线条数自动选
  ③ 精确模式（1 条：整条当矿界、界内按品位分块）或 ② 人工圈矿（≥2 条：每条线一块）；
* 窗口标题带版本号（本版 **v1.3**），改了代码请关掉旧窗口重新启动；
* DWG 被 CAD 占用时自动另存 `<名>_2010_new.dwg`；AutoCAD 没开时第 2/3 步自动拉起；
* 报告表格无底纹；拖拽支持；四个 .bat（启动/跑验收/看参数台账/首次运行检查）。
