## 二次圈矿工具 v1.1

### 新功能：**把文件从资源管理器直接拖进窗口**

不用再一个个点"浏览…"了。往界面上拖，按类型自动落位：

| 拖进来的东西 | 落到哪 / 会发生什么 |
|---|---|
| **炮孔数据库 Excel**（`.xls/.xlsx`） | 数据库栏；并自动**识别平台/日期**、自动找同目录的**综合图**、自动填**输出目录** |
| 名字里带"**综合**"的 `.dwg` | 综合图栏 |
| 其它 `.dwg`（一般就是该炮区的人工圈矿图，形如 `…二次圈矿矿块图1011.dwg`） | 记成"人工圈矿图"——点「用人工图标定本炮区…」会**直接用它**，不再弹选择框；同时按名字识别平台/日期 |
| `.3ds`（可一次拖好几个） | "精确模式轮廓文件"栏（分号分隔），填了就照人工画的矿界出图 |
| **文件夹** | 输出目录 |

一次可以把一天的三样（数据库 + 人工图 + 综合图）一起拖进来，界面就填好了。

拖拽依赖 `tkinterdnd2`（`pip install tkinterdnd2`，本机已装；`首次运行检查.bat` 会检查并提示）。
**没装也不影响**其它功能，只是不能用拖拽，各栏照旧用「浏览…」。

### 同时包含 v1.0.1 的修复

* 机器上 **AutoCAD 没开着** 时，第 2 步（DXF → DWG 2010）与第 3 步（并入综合图副本）
  以前会直接失败；现在**会自动帮你拉起 AutoCAD**（首次 30~60 秒，日志有提示），拉起来后正常完成；
* 交给 AutoCAD 的文件路径改成**绝对路径**（相对路径会让 AutoCAD 报"未找到文件 xxx"）；
* 失败提示改成可操作的话（DXF 已保留、可手工另存 2010、或取消勾选跳过）。

## 附：工具整体说明（v1.0 那份）

丢给它两个文件就能出三件套：**炮孔数据库 Excel** + 该平台的**年度综合图 DWG** →
① 炮孔数据报告（xlsx + 图片版 png）② 二次圈矿矿块图（DXF，可转 DWG 2010）③ 矿块边界线 .3ds。

**核心**：自动圈连矿块——按走向中线分左右链 → 逐段法向外推 → 端部按"外推 / 1/2 工程间距"闭合
→ 与综合图能贴上的一段改走历史矿块边界 → 界内按品位档 + Voronoi 算量分块定档。

### 验收状态（17 个真实炮区，全绿）

| 平台 | 炮区 | 矿界 IoU | 体积差（自动 vs 人工） | 块数 |
|---|---|---|---|---|
| 3940 | 0915 / 0922 / 1003 / 1004 / 1008 | 0.62 ~ 0.95 | −1.3% ~ +6.1%（基准＝人工报告） | 全部与人工图一致 |
| 3960 | 12 个炮区（0825…1009） | 0.53 ~ 0.93 | −2.9% ~ +6.8%（基准＝人工图算） | 全部与人工图一致 |

四项自检都进了 `跑验收.bat`：圈矿闸门两档、报告口径回归、成果图实体自检、精确模式自检。

### 怎么用（Windows）

1. 双击 **`首次运行检查.bat`** —— 环境自检（Python / 依赖 / 数据目录 / 参数 / 输出目录 / AutoCAD）；
2. 双击 **`启动二次圈矿工具.bat`** —— 界面：拖文件进来或点「浏览…」→ 平台/日期 → **一键出三件套**；
3. 想自查：**`跑验收.bat`**（全套约 3 分钟）/ **`看参数台账.bat`**。

需要 Python 3.10+ 与 `numpy scipy shapely matplotlib ezdxf openpyxl xlrd`；
可选：`tkinterdnd2`（拖拽）、AutoCAD（读综合图历史块 / 转 DWG2010）。

### 已知差异（不是 bug）

* 3960 的 0922 / 1007 这类炮区，人工图是**手画的"两瓣收腰"形状**，自动是"孔簇领地"连片，
  形状 IoU 只有 0.53~0.54——但**面积比 1.00~1.02、体积差 +0.2% / −0.5%**（量是对的）。
  要做到形状完全一致，用**精确模式**：把人工画好的矿界导出 .3ds 导入即可（1008 实测 IoU 0.962）。
* 3940 的年度综合图里含**当日本身已经圈过的块**，所以验收里另有一档"严格对账"
  （把当日本身的块排掉，模拟新炮区）——那一档的数字才是新炮区的真实水平。

### 安全边界

真实矿山数据**只读**；"并入综合图"一律先出**副本**，替换原件必须人工确认（有备份可回退）；
不要改动 3DMine 安装目录。
