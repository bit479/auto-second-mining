## 二次圈矿工具 v1.2

### 新功能 ①：**人工圈矿模式**——你自己圈，程序只算量出图

你按需求提的：不用程序自己圈矿，**你在 3DMine 里圈好并导出 .3ds**，交给程序算量、出报告和成果图。

用法：把 .3ds 填进参数区的"轮廓文件"栏（也可以直接**拖进窗口**），并**勾上"人工圈矿模式"**。

* **一条闭合线 = 一块**（.3ds 里几条线就是几块；不合并、不抽稀、不外推）；
* 算量口径与自动模式**完全一致**：体积 = Σ(全场孔 Voronoi 单元 ∩ 你画的范围 × 该孔 gradeLenght)；
  重量按单元所在档取容重（<0.5 取 2.65，其余 2.7）；品位 = 块内孔按孔长加权；
  金属量 = 重量×品位÷100（百克，3 位小数）；体号按品位档从高到低重排（与人工报告一致）；
* 不勾那个框就是原来的**精确模式**：整条 .3ds 当**矿界**，界内程序仍按品位档再分块；
* 命令行也行：`python core\run_strip.py <库.xls> <平台> <炮区> <输出目录> <综合图.dwg> --manual-blocks a.3ds;b.3ds`

**拿你给的 3970-1011 试过**（`选择集对象分品位.3ds` 两条线 → 2 块）：

| | 本工具 | 你的 3DMine 报告（10-13） |
|---|---|---|
| 合计体积 | 9268.089 m³ | 9087.284 m³（**+2.0%**） |
| 合计重量 | 24945.712 t | 24535.665 t（+1.7%） |
| 合计品位 | 0.678 | 0.671 |
| 合计金属量 | 169.153 百克 | 164.655 百克（+2.7%） |

其中大块（24 孔那块）**+0.4%**、品位 0.651 两边完全一致；小块的差别来自
"你 10-13 报告用的那个多边形比今天这份 .3ds 里的线小"（反推面积 30.5 vs 42.8 m²）。

### 新功能 ②：报告表格**去掉单元格底纹**

按你的要求，表头（原来浅蓝）与小计行（原来浅灰）现在都改成**无色透明**；插进成果图的那张
报告图片同步改掉。边框、字体、居中不变。

## 附：整个工具是什么

给它两个文件：**炮孔数据库 Excel** + 该平台的**年度综合图 DWG** →
① 炮孔数据报告（xlsx + 图片版 png）② 二次圈矿矿块图（DXF，可转 DWG 2010）③ 矿块边界线 .3ds。

自动档的核心：按走向中线分左右链 → 逐段法向外推 → 端部按"外推 / 1/2 工程间距"闭合 →
与综合图能贴上的一段改走历史矿块边界 → 界内按品位档 + Voronoi 算量分块定档。

### 怎么用（Windows）

1. 双击 **`首次运行检查.bat`** —— 环境自检（Python/依赖/数据目录/参数/输出目录/AutoCAD）；
2. 双击 **`启动二次圈矿工具.bat`** —— 拖文件进来或点「浏览…」→ 平台/日期 → **一键出三件套**
   （要用人工圈矿模式就勾上那个框）；
3. 想自查：**`跑验收.bat`** / **`看参数台账.bat`**。

需要 Python 3.10+ 与 `numpy scipy shapely matplotlib ezdxf openpyxl xlrd`；
可选：`tkinterdnd2`（拖拽）、AutoCAD（读综合图历史块 / 转 DWG2010；没开也会自动拉起）。
