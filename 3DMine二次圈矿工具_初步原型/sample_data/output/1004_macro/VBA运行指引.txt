# 3DMine VBA 宏运行指引（1004 二次圈矿）

## 背景
- 3DMine 的 Python 宏（PyMacro 菜单）在此版本实例中未启用（点击无反应，已确认）。
- 3DMine 自带 **VBA 宏功能**（官方 demo 中有 30 多个 VBA 示例工程，功能确定存在）。
- 本指引使用 3DMine 的 VBA 编辑器在 **3DMine 内**绘制：炮孔点（带品位）、矿块闭合线、1m 网格、矿块号标注，并出具数据报告。

## 步骤（约 2 分钟）

### 1. 重启 3DMine
> 必须重启：菜单配置在启动时加载，重启后才会出现新增的「宏」菜单。

### 2. 打开宏菜单
菜单栏应出现 **「宏(V)」** 菜单（在「文件」左边），含 5 项：
- 运行宏 / 宏安全设置 / 加载工程 / 新建工程 / VBA编辑器

### 3. 新建工程
点击 **宏 → 新建工程**（会提示保存位置，随便选一个目录保存即可，如 D:\WK\N CRT\3DMine二次圈矿工具_初步原型\3dmine_scripts\）。

### 4. 打开 VBA 编辑器
点击 **宏 → VBA编辑器**，应弹出 VBA 编辑窗口，左侧工程树有 **ThisDrawing** 模块。

### 5. 粘贴代码
- 用记事本打开：`D:\WK\N CRT\3DMine二次圈矿工具_初步原型\3dmine_scripts\mine_1004_vba.bas`
- 全选复制（Ctrl+A → Ctrl+C）
- 在 VBA 编辑器里双击 **ThisDrawing** 模块，把代码全部粘贴进去（Ctrl+A 全选原内容后 Ctrl+V）

### 6. 运行
- 在 VBA 编辑器里按 **F5**（或菜单 运行 → 运行子过程/用户窗体，选 **OreDelineation**）
- 若弹出"宏可能包含病毒"提示，选择允许/启用内容

### 7. 查看结果
运行完成会弹窗提示数量统计。3DMine 图中将出现：
- 炮孔点 + 品位小字标注（如 `1.424`）
- 矿块闭合线（3 块：1.5-3 两块 + 0.5-1 一块）
- 每个矿块的 1m 网格线
- 矿块号标注（矿块1/矿块2/矿块3）
- 报告写入：`output\1004_macro\1004_矿块数据报告.txt`

## 如果 VBA 编辑器打不开或运行报错
把报错内容截图或文字发给我，我来调整代码。VBA 编辑器打不开 = 该实例 VBA 功能也被限制，那就需要联系 3DMine 技术支持启用 Python 宏（发布说明显示 2022 版有"菜单连接脚本"功能，正常版应可用）。
